# Du Bois's wrapped bars

<Lead>W. E. B. Du Bois's charts for the 1900 Paris Exposition fold a bar that is too long for the page back on itself, so a large value and a small one share one scale. This page builds the Du Bois wrapped bar chart step by step, then rebuilds four of his charts the same way: a [`track`](/marks/track) draws each bar as a length along a route, and `move()` on its `length` writes the value.</Lead>

<Section id="threshold" title="Step by step: a wrapped bar chart">

The Du Bois wrapped bar chart (Karduni et al., CHI 2020) turns his fold into a rule. A bar runs to a **threshold**, turns down, and runs back. Here every lane runs the full width, so each one holds the threshold.

**1. Declare the answer.** One row per bar. The `schema` gives `value` its type and domain.

```js
data: [{ name: "A", value: 3000 }, { name: "B", value: 1750 }, /* … */],
schema: {
  name:  { type: "categorical" },
  value: { type: "quantitative", domain: [0, MAX] },
},
```

**2. Choose the threshold and the wrap.** The first lane holds `THRESH`. Each lane after it runs back to `WRAP * THRESH`, so it holds `LANE`. With `WRAP = 0` a lane runs back to zero and holds `THRESH`. A wrap steps down `STEP` of a row.

```js
const THRESH = 1500, WRAP = 0, MAX = 6000;
const LANE = (1 - WRAP) * THRESH;   // 1,500
const STEP = 0.3;
```

**3. Map data units to pixels.** Two linear scales do it: `x` maps `[0, THRESH]` across the plot, and `y` gives each level one row. `x` is linear, so every lane has the same pixels per unit.

```js
const x = (v) => X0 + (v / THRESH) * W;
const y = (level) => TOP + level * ROW;
```

**4. Give each row its level.** A row starts below the rows before it, plus the steps their wraps take. The level reads the live rows, so when a bar wraps into another lane, the rows below it move down.

```js
const wraps = (v) => (v > THRESH ? Math.ceil((v - THRESH) / LANE - 1e-9) : 0);
const levelOf = (i, rows) =>
  rows.slice(0, i).reduce((level, d) => level + 1 + STEP * wraps(d.value), 0);
```

**5. Write the route.** The **route** is the longest bar a row allows, as an SVG path. Each `M` starts a lane. The route runs right to `THRESH`, steps down, runs back to `WRAP * THRESH`, and repeats until it holds `MAX`. Only lanes hold value, so the steps between them count for nothing.

```js
function routeOf(i, rows) {
  let level = levelOf(i, rows), from = 0, to = THRESH, held = THRESH;
  let d = `M${x(from)},${y(level)}L${x(to)},${y(level)}`;
  while (held < MAX) {
    level += STEP;
    [from, to] = [to, to === THRESH ? WRAP * THRESH : THRESH];
    d += `M${x(from)},${y(level)}L${x(to)},${y(level)}`;
    held += LANE;
  }
  return d;
}
```

**6. Draw the bar along the route.** A `track` takes the route as `path`. Its `length` channel binds `value`: the schema's domain spans the whole route, so 6,000 fills all four lanes and 750 half of the first. `join: "round"` draws each step down as a half circle that bulges outward. `stroke` colours the bar by its value, from teal to red.

```js
track({
  path: (d, i, rows) => routeOf(i, rows),
  join: "round",
  channels: {
    length: { field: "value", edit: move() },
    stroke: { field: "value", scale: { range: ["teal", "red"] } },
    strokeWidth: { value: 7 },
  },
}),
```

**7. Drag the end of the bar.** `move()` on `length` puts the end of the bar at the point of the route nearest the pointer. It follows the route from where the bar ends, so drag round a turn to carry the bar into the next lane. You can press anywhere on a row's route, even where no bar is drawn, so a bar at zero can still be grabbed. Every redraw reads the new value, so the bar, its colour and the rows below follow it.

`constraints: [snap({ step: 1 })]` keeps each answer a whole number.

**8. Add the axis.** A `guides.custom` draws the x axis over `[0, THRESH]`.

<Section id="steps" title="Du Bois's charts">

The four charts below use the same `track` and the same `move()` on `length`. Drag the end of a bar along its route. Only the route changes. The first two are wrapped bars in data units, with `WRAP = 0` and a row per level. A coil and a spiral are geometry, so their routes are written in pixels.

Every row's route holds the same length, so the rows share one scale.

</Section>

<Section id="furniture" title="A spiral">

Each year starts at the top and runs clockwise. Its radius shrinks by six bands a turn, so the turns of all six years nest without touching. The value is the length of the spiral, so an outer turn holds more than an inner one. Each year's spiral is cut to the same length, which holds $1,600,000.

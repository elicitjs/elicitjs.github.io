# Du Bois's wrapped bars

<Lead>W. E. B. Du Bois's charts for the 1900 Paris Exposition fold a bar that is too long for the page back on itself, so a large value and a small one share one scale. This page builds the Du Bois wrapped bar chart step by step, then rebuilds four of his charts the same way: a `shape` draws each bar along a track from its value, and a `slide` on its length writes the value.</Lead>

<Section id="threshold" title="Step by step: a wrapped bar chart">

The Du Bois wrapped bar chart (Karduni et al., CHI 2020) turns his fold into a rule. A bar runs to a **threshold**, turns down, and runs back. Here every lane runs the full width, so each one holds the threshold.

**1. Declare the answer.** One row per bar. The `schema` gives `value` its type and domain.

```js
data: [{ name: "A", value: 3000 }, { name: "B", value: 1750 }, /* … */],
schema: {
  name:  { type: "categorical" },
  value: { type: "quantitative", domain: [0, MAX] },
},
```

**2. Choose the threshold and the wrap.** The first lane holds `THRESH`. Each lane after it runs back to `WRAP * THRESH`, so it holds `LANE`. With `WRAP = 0` a lane runs back to zero and holds `THRESH`. A wrap steps down `STEP` of a row.

```js
const THRESH = 1500, WRAP = 0, MAX = 6000;
const LANE = (1 - WRAP) * THRESH;   // 1,500
const STEP = 0.3;
```

**3. Write the track in data units.** A **track** is the longest bar a row allows, as `[value, level, turn]` points. It runs right to `THRESH`, steps down, runs back to `WRAP * THRESH`, steps down, and repeats until it holds `MAX`. A point marked `turn` ends a step down. Steps hold no value.

```js
function trackOf(i, rows) {
  let level = levelOf(i, rows), end = THRESH, held = THRESH;
  const points = [[0, level], [THRESH, level]];
  while (held < MAX) {
    level += STEP;
    points.push([end, level, true]);
    end = end === THRESH ? WRAP * THRESH : THRESH;
    points.push([end, level]);
    held += LANE;
  }
  return toPixels(points);
}
```

**4. Map the track to pixels.** Two linear scales do it: `x` maps `[0, THRESH]` across the plot, and `y` gives each level one row. `x` is linear, so every lane has the same pixels per unit, `per = W / THRESH`. `toPixels` maps each point, and rounds each step down into a half circle that bulges outward.

```js
const x = (v) => X0 + (v / THRESH) * W;
const y = (level) => TOP + level * ROW;

function toPixels(points) {
  const r = (STEP * ROW) / 2;
  return points.flatMap(([v, level, turn]) => {
    if (!turn) return [[x(v), y(level)]];
    const side = v === THRESH ? 1 : -1, top = y(level) - 2 * r;
    return Array.from({ length: 8 }, (_, a) => {
      const t = ((a + 1) / 8) * Math.PI;
      return [x(v) + side * r * Math.sin(t), top + r - r * Math.cos(t), true];
    });
  });
}
```

**5. Give each row its level.** A row starts below the rows before it, plus the steps their wraps take. The level reads the live rows, so when a bar wraps into another lane, the rows below it move down.

```js
const wraps = (v) => (v > THRESH ? Math.ceil((v - THRESH) / LANE - 1e-9) : 0);
const levelOf = (i, rows) =>
  rows.slice(0, i).reduce((level, d) => level + 1 + STEP * wraps(d.value), 0);
```

**6. Draw the bar from the value.** `along(track, length)` keeps the first `length` pixels of lane, and `pathOf` turns those points into an SVG path. A `shape` draws the path. A `shape` fits its path to a box, so the bar states its centre (`x`, `y`) and half-size (`size`) as `fn` channels. `stroke` colours the bar by its value, from teal to red.

```js
const at = (d, i, rows) => pathOf(along(trackOf(i, rows), d.value * per));
shape({
  path: (d, i, rows) => at(d, i, rows).d,
  channels: {
    x: { fn: (d, i, rows) => at(d, i, rows).x },
    y: { fn: (d, i, rows) => at(d, i, rows).y },
    size: { fn: (d, i, rows) => at(d, i, rows).size },
    fill: { value: "none" }, strokeWidth: { value: 7 },
    stroke: { field: "value", scale: { range: ["teal", "red"] } },
    length: /* step 7 */,
  },
});
```

**7. Slide the length.** A `length` channel binds `value`, and a [`slide`](/editing/gestures#slide) on it writes it. Drag down and the value grows; drag up and it shrinks. The value changes by how far you drag from where you pressed, so it never jumps to another lane. `extent` is the drag that covers the whole domain: 480px for 0 to 6,000. Every redraw reads the new value, so the bar, its colour and the rows below follow it.

```js
length: { field: "value", edit: slide({ axis: "y", increase: "down", extent: 480 }) },
```

`constraints: [snap({ step: 1 })]` keeps each answer a whole number.

**8. Add a groove and the axis.** A faint `shape` one lane long sits under each bar and carries the same `slide`, so a bar at zero can still be grabbed. `foldedBar` returns the groove and the bar together. A `guides.custom` draws the x axis over `[0, THRESH]`.

```js
...foldedBar({
  trackOf, field: "value", per: W / THRESH, groove: W, travel: 480,
  stroke: { field: "value", scale: { range: ["teal", "red"] } }, width: 7,
}),
```

The four charts below use the same helpers and the same `slide` on `length`: press on a bar or its groove and drag down to grow it, up to shrink it. Only `trackOf` and `travel` change. The first two tracks are wrapped bars in data units, with `WRAP = 0` and a row per level. A coil and a spiral are geometry, so their tracks are written in pixels, and `per` is pixels per unit.

</Section>

<Section id="religion" title="A square coil">

The track runs right along the bottom, up, back left and down, then turns inward one step and goes round again. Each side is one step shorter than the side before it on that axis. The corners are square and carry no `turn` points, so every pixel of the coil holds value. `travel: 500` covers 0 to 4,000,000, so one pixel of drag is 8,000 people.

Each year starts at the top and runs clockwise. Its radius shrinks by six bands a turn, so the turns of all six years nest without touching. The value is the length of the spiral, so an outer turn holds more than an inner one. `travel: 400` covers $0 to $1,600,000.

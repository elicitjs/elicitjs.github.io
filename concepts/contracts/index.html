Mark & element contracts

What every factory is for: kind, channels, whether create/remove apply, and what you grab. Prefer elicit.elements.* for scale chrome. The same factories stay aliased on plot.*.

Four kinds

KindMeaning
dataViews dataset rows; channels name columns
parametricBelief parameters (trend); not free create targets
map chromeBasemap / tiles; pointer-transparent
elementViews a SCALE (views: 'scale'); domain edits, not row creates

Marks are inert until an edit names the column it writes. Edits write fields — a constant { value } channel cannot carry an edit.

Guides and effects

A guide shows a rule (edit.guide — bounds / catchment / track). An effect shows state (hovered / selected / grabbed). Proximity picks (nearest, sweep, brush*) auto-enable catchment when you omit guide; set guide: false to silence. See Guides and Effects.

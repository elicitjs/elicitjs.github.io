ElicitJS

A declarative library for visual belief elicitation. Build a chart people fill in: they drag a bar, place a point or turn a dial, and you get structured data back.

Get started →API referencePlaygroundGitHub$ npm install elicitjs

Alpha: pre-1.0 and under active development, so expect breaking changes. ESM-only, with d3 v7 as a peer dependency.

What you can elicit

Each chart below is live. Drag it, and the data it produces updates beside it.

How would you allocate 100% across these categories?

Use a bar chart when the pieces have to add up. Drag any bar; the others adjust so the total stays 100.

Allocate a budget

Drag the bars to split 100% across categories. Raising one lowers the others.

Try: Drag any bar. The shares always add up to 100.

Where do people sit on age vs immigration attitude?

Use a scatter plot to ask a two-part question. The chart starts empty — double-click to add someone, then drag them into place.

Age vs immigration attitude

An empty scatter plot. Double-click to place people; drag to move them. Colour runs from red (anti) to green (pro).

Try: Double-click to add a person · drag to move them.

What trend do you expect over time?

Use a line chart when you want someone to draw a path. Drag across the chart to sketch the forecast you have in mind.

Draw the trend you expect

Sketch the line with your mouse — like drawing a forecast by hand.

Try: Drag left-to-right across the chart to reshape the line.

How likely is Candidate D to win?

Use a needle dial for a single choice on a scale — from “very likely D” to “very likely R.” Drag the needle to answer.

Likelihood gauge

A dial you can turn — drag the needle to pick how likely something feels.

Try: Drag the needle left or right.

Where do you think is the best place to live in Vancouver?

Place pins on a map to answer. Click to drop a pin; drag one to move it.

Best place to live

Click the map to drop pins for places you’d live; drag a pin to fine-tune.

Try: Click to place a pin · drag an existing one.

How easy is this tool to use?

Classic survey scales work too. Hover to preview, then click to lock in an answer.

Answer a survey scale

A familiar agree/disagree question — hover, then click your answer.

Try: Hover across the scale, then click your answer.

What happened to U.S. traffic deaths after 1990?

The New York Times' “You Draw It” format: 1968–1990 is historical record (locked), 1991–2016 is what you draw. When you finish, press the button to reveal the answer key.

Draw the missing years

Drag across the empty space to draw 1991–2016, then advance to reveal the truth.

Try: Drag left-to-right to draw the missing years · then press Show me how I did.

How a chart is built

Under the hood it’s a short recipe: starting data, what each field means, and a chart type with dragging turned on. The panel on the right is the answer you collect.

One editable bar chart

The chart on the left and the numbers on the right are the same thing — drag a bar and watch the data update.

Try: Drag a bar — the panel on the right is what your app would read.
mount(Elicit({
  width: 560, height: 280,
  responsive: "reflow",
  margins: { top: 24, right: 20, bottom: 44, left: 48 },
  // 1. Starting numbers
  data: [
    { cat: "A", n: 30 },
    { cat: "B", n: 55 },
    { cat: "C", n: 22 },
    { cat: "D", n: 44 },
  ],
  // 2. What each column means (and its range)
  schema: {
    cat: { type: "categorical", domain: ["A", "B", "C", "D"] },
    n:   { type: "quantitative", domain: [0, 60] },
  },
  // 3. Draw bars; dragging a bar changes its number
  marks: [
    bar({
      fill: "#4f46e5",
      channels: {
        x: { field: "cat" },
        y: { field: "n", edit: move() },
      },
    }),
  ],
}))

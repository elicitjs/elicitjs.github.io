Mark-specific & path edits

Certain marks maintain multi-row or geometric invariants that require specialised edits. edit.line.sweep() repaints points across columns, edit.line.anchor() builds connected paths, and edit.stack.edge() and edit.stack.cut() reallocate slices in pies and stacked bars.

API reference

edit.line.sweep(options)

You-draw-it painting: a drag repaints the value of every point the pointer crosses. A move under the sweep driver, so it inverts the pointer through the same scale.

edit.line.sweep({ guide, series, when, stage }) → Edit
Options
OptionTypeDefaultDescription
guidebooleantrueDraw tracking indicators along the swept column.
mode'absolute''absolute'A sweep paints the pointer's position, so 'relative' has no meaning here and warns.
Returns / emits

An Edit scoped to line. It needs a mark that groups points into series.

edit.line.draw(options)

Freehand path sampling, or a you-draw-it upsert on a line mark.

edit.line.draw({ along, value, samples, minDist, series, threshold, into }) → Edit
Options
OptionTypeDefaultDescription
along / value'x' | 'y''x' / 'y'The independent axis to draw along, and the dependent value axis.
samplesnumber | any[]the scale's ticksDomain grid points the drawn value snaps to: a count, explicit positions, or a time interval.
minDistnumber8How far the pointer must travel, in px, before another freehand point is sampled.
seriesstringthe mark's series fieldThe column that carries the series key. Override it when the drawn line groups by something other than the mark's own grouping channel.
into'nearest' | 'new''nearest'Append to the nearest line, or start a fresh series.

edit.line.anchor(options)

Click to add anchor points to a line, one at a time.

edit.line.anchor({ into, series, gesture, when }) → Edit
Options
OptionTypeDefaultDescription
into'nearest' | 'new''nearest'Add the point to the closest existing series, or start a new one. A click in empty space under 'nearest' also starts a fresh series.
seriesstringthe mark's series fieldThe column the new point's series key is written to.

edit.line.newSeries(options)

Seed a whole line at once — one anchor per sampled domain position, all at the pointer’s value. The draw-from-scratch primitive; pair it with sweep to shape the flat line it leaves.

edit.line.newSeries({ along, value, samples, series }) → Edit
Options
OptionTypeDefaultDescription
along / value'x' | 'y''x' / 'y'The axis the line runs along, and the axis it carries a value on.
samplesnumber | any[]the scale's ticksWhere the anchors go: a count, explicit domain positions, or a time interval.
seriesstringthe mark's series fieldThe column the new series key is written to.

edit.line.removeSeries(options)

Delete a whole line. Clicking any point on it reads that point’s series key and drops every row sharing it — the counterpart to remove, which drops one anchor.

edit.line.removeSeries({ series, gesture, when }) → Edit
Options
OptionTypeDefaultDescription
seriesstringthe mark's series fieldThe column that identifies the line.
gesture / whenstring / (ctx) => boolean'click' / —Pair them with a when if another click edit shares the mark — removing one point against removing the whole line.

edit.stack.cut(options)

Click inside a stacked segment to divide it into two, taking the next category from the schema's domain.

edit.stack.cut({ label, categoryField, defaults, when }) → Edit
Options
OptionTypeDefaultDescription
categoryFieldstringthe stack's category columnWhich column carries the segment's identity, when the stack groups by more than one.
labelstring—The placeholder name a new segment takes on an open domain, which has no next category to hand out.
defaultsobject{}Extra fields to seed the new row with, over the schema's defaults.

edit.stack.edge(options)

Drag a boundary to move value between the two segments it separates. Only those two change — one grows by exactly what the other loses — so the group’s total is preserved by construction.

edit.stack.edge(options?) → Edit
Options
OptionTypeDefaultDescription
—EditOptions—The universal edit options. The boundary it drags is resolved from the mark's own layout.

edit.stack.merge(options)

Double-click a boundary to fuse the two segments it separates back into one. The inverse of cut, preserving the same total: the lower row survives and takes the pair’s whole magnitude.

edit.stack.merge(options?) → Edit
Options
OptionTypeDefaultDescription
—EditOptions—The universal edit options. It removes a row, not a category, so the domain is left alone and cutting brings that category back.

Line sweep (you-draw-it)

edit.line.sweep() updates each point's value as the pointer crosses its horizontal column — the canonical "you-draw-it" interaction. The $x$ coordinates remain fixed while the curve conforms to the gesture.

Sweep to shape a curve

edit: move({ pick: "sweep" }) on the y channel paints values as you drag horizontally.

mount(Elicit({
  width: 420, height: 260,
  margins: { top: 14, right: 14, bottom: 26, left: 30 },
  data: [
    { x: 0, y: 50 }, { x: 1, y: 50 }, { x: 2, y: 50 }, { x: 3, y: 50 },
    { x: 4, y: 50 }, { x: 5, y: 50 }, { x: 6, y: 50 }, { x: 7, y: 50 },
  ],
  schema: {
    x: { type: "quantitative", domain: [0, 7] },
    y: { type: "quantitative", domain: [0, 100] },
  },
  marks: [
    lineY({
      stroke: "#4f46e5", strokeWidth: 3, curve: "catmullRom",
      channels: {
        x: { field: "x" },
        y: { field: "y",
             edit: move({ pick: "sweep", guide: true }) },
      },
    }),
  ],
}))
Try: Sweep left-to-right across the chart.

Series-scoped multi-line sweeps

When multiple lines share a plot, a sweep locks onto the nearest line at drag-start and paints only that series. Other series remain untouched.

Two lines swept independently

The sweep locks onto the closest series at the start of the drag.

mount(Elicit({
  width: 420, height: 260,
  margins: { top: 14, right: 14, bottom: 26, left: 30 },
  data: [
    { g: "plan",   x: 0, y: 30 }, { g: "plan",   x: 1, y: 45 }, { g: "plan",   x: 2, y: 40 }, { g: "plan",   x: 3, y: 60 },
    { g: "actual", x: 0, y: 70 }, { g: "actual", x: 1, y: 62 }, { g: "actual", x: 2, y: 75 }, { g: "actual", x: 3, y: 68 },
  ],
  schema: {
    x: { type: "quantitative", domain: [0, 3] },
    y: { type: "quantitative", domain: [0, 100] },
    g: { type: "categorical" },  // a group identifier, not an ordered scale
  },
  marks: [
    lineY({
      strokeWidth: 3, curve: "catmullRom",
      channels: {
        x: { field: "x" },
        y: { field: "y",
             edit: move({ pick: "sweep", guide: true }) },
        stroke: { field: "g" },
      },
    }),
  ],
}))
Try: Sweep over one line to reshape it; the other remains fixed.

Line anchors & freehand paths

edit.line.anchor() appends new points to the nearest line or starts a fresh series in empty space. edit.line.draw() samples pointer movement to record freehand continuous strokes.

Click to add an anchor

Clicking empty space appends the next anchor point to the line.

mount(Elicit({
  width: 380, height: 220,
  margins: { top: 16, right: 16, bottom: 28, left: 34 },
  data: [
    { step: 1, val: 20 },
    { step: 2, val: 50 },
    { step: 3, val: 35 },
  ],
  schema: {
    step: { type: "quantitative", domain: [1, 6] },
    val:  { type: "quantitative", domain: [0, 100] },
  },
  marks: [
    line({
      stroke: "#2563eb",
      channels: {
        x: { field: "step" },
        y: { field: "val", edit: move() },
      },
      edits: [
        edit.line.anchor({ into: "nearest" }),
      ],
    }),
  ],
}));
Try: Drag an existing point, or click empty space to append an anchor.

Arc slices & stacked bars

Stacked marks (such as pie, donut, and barY) use edit.stack.edge() and edit.stack.cut() to modify proportions while holding the total constant.

edit.stack.edge() lets you drag interior seams between segments. edit.stack.cut() clicks inside a segment to split it into distinct categories drawn from the schema domain.

Cut a stack into categories

Click inside a 100% bar to cut it into categories; drag seams to adjust proportions.

mount(Elicit({
  width: 380, height: 220,
  margins: { top: 16, right: 16, bottom: 28, left: 40 },
  data: [
    { year: "2024", share: 100, asset: "Stocks" },
  ],
  schema: {
    year:  { type: "categorical", domain: ["2024"] },
    asset: { type: "categorical", domain: ["Stocks", "Bonds", "Cash", "Real Estate"] },
    share: { type: "quantitative", domain: [0, 100] },
  },
  marks: [
    barY({
      stack: true,
      channels: {
        x: { field: "year" },
        y: { field: "share" },
        fill: { field: "asset" },
      },
      edits: [
        edit.stack.cut(),
        edit.stack.edge(),
      ],
    }),
  ],
}));
Try: Click inside the bar to cut it into asset categories · drag seams to rebalance.

Pie slice boundary redistribution

edit.stack.edge() on a pie mark redistributes adjacent shares.

mount(Elicit({
  width: 300, height: 260,
  margins: { top: 20, right: 20, bottom: 20, left: 20 },
  axes: false,
  data: [
    { cat: "A", val: 50 },
    { cat: "B", val: 30 },
    { cat: "C", val: 20 },
  ],
  schema: {
    cat: { type: "categorical" },
    val: { type: "quantitative", domain: [0, 100] },
  },
  marks: [
    arc({
      outerRadius: 95,
      edits: [edit.stack.edge()],
      channels: {
        theta: { field: "val" },
        fill: { field: "cat" },
      },
    }),
  ],
}));
Try: Drag any slice seam to shift proportions between adjacent categories.

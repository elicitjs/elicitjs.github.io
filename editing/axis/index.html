Editable axes (domain)

An axis is normally inert. Give it an edit and it becomes interactive — but where a mark edit rewrites a datum, an axis edit rewrites the field's domain on the schema. A numeric axis is dragged to grow or shrink its range; a categorical axis gains add / rename / remove affordances. Because the domain lives on the schema and scales re-resolve every render, the grid, guides and marks follow along automatically. Read the new domain with el.getSchema() (the dataset is untouched, except that removing a category also deletes its rows).

API reference

edit.axis.scale(options)

Numeric / temporal axis — drag an end-handle to rescale the range. Runs through the axisDrag driver (the plane owns the gesture); apply writes the new [min,max].

edit.axis.scale({ field, mode }) → Edit
Options
OptionTypeDefaultDescription
fieldstringall on axisThe schema field whose domain to write. Defaults to every field unioned onto the axis (e.g. an error bar's mean/lo/hi).
mode'rescale'|'grow''rescale'rescale keeps the chart size (marks compress); grow holds the data's pixels-per-unit and resizes the chart instead.
Returns / emits

An Edit with target: "domain". apply returns { domains, resize? }; the engine writes the schema (and resizes in grow mode).

edit.scale.categories(options)

Categorical / ordinal SCALE — add, rename and remove categories, from any element that draws it (an axis or a legend). Reuses the inline-typing lifecycle: double-click the "＋" to add, double-click a label or swatch to rename, click its "×" to remove. Renaming and removing write every column on the scale, in every table it spans.

edit.scale.categories({ field, mode }) → Edit[]
Options
OptionTypeDefaultDescription
fieldstringfirst on axisThe categorical field whose domain (and rows, on rename/remove) to edit. Unset, every field on the scale is written.
mode'rescale'|'grow''rescale'rescale keeps the chart size (bands re-divide it — thinner as you add); grow keeps each band the same pixel size and grows/shrinks the chart by a step per category (e.g. a 5-point Likert extended to 7).
Returns / emits

An array of Edits (add / rename / remove), all target: "domain". Rename relabels matching rows; remove deletes them. In grow mode, add/remove also carry a chart resize.

Drag a numeric axis to rescale

axisX(\{ edit: edit.axis.scale() \}) grows a draggable handle at each end of the axis. Drag the max handle inward to widen the range (data compresses into the same chart), outward to tighten it. The min stays anchored; the dataset never changes.

Rescale in place

Dragging the end-handle rewrites x's schema domain; the grid follows.

mount(Elicit({
  width: 420, height: 280,
  margins: { top: 16, right: 18, bottom: 40, left: 44 },
  data: [{ x: 20, y: 30 }, { x: 55, y: 65 }, { x: 90, y: 20 }],
  schema: {
    x: { type: "quantitative", domain: [0, 100] },
    y: { type: "quantitative", domain: [0, 100] },
  },
  axes: false,
  marks: [
    gridX(), axisY(),
    axisX({ title: "x", grid: true, edit: edit.axis.scale() }),
    point({ fill: "#7c3aed", size: 7,
      channels: { x: { field: "x" }, y: { field: "y" } } }),
  ],
}))
Try: Drag the blue handle at either end of the x-axis.

Grow the chart instead

mode: 'grow' holds the data's scale constant and resizes the chart.

mount(Elicit({
  width: 360, height: 260,
  margins: { top: 16, right: 18, bottom: 40, left: 44 },
  data: [{ x: 20, y: 30 }, { x: 90, y: 55 }],
  schema: {
    x: { type: "quantitative", domain: [0, 100] },
    y: { type: "quantitative", domain: [0, 100] },
  },
  axes: false,
  marks: [
    axisY(),
    axisX({ title: "x", edit: edit.axis.scale({ mode: "grow" }) }),
    point({ fill: "#059669", size: 7,
      channels: { x: { field: "x" }, y: { field: "y" } } }),
  ],
}))
Try: Drag the x-axis max handle — the chart itself grows/shrinks.

Add, rename & remove categories

axisX(\{ edit: edit.scale.categories() \}) turns each category label into a rename target (double-click to type), gives each an × to remove, and adds a ＋ at the end to append a new one. Renaming relabels matching rows; removing deletes them — schema and data stay in step.

The domain belongs to the scale, not to the axis, so the same edit works on any element drawing that scale — a legend takes it too. Where one scale spans several columns, or several tables, every one is written.

Edit the category list

Double-click ＋ to add · double-click a label to rename · click × to remove.

mount(Elicit({
  width: 420, height: 280,
  margins: { top: 16, right: 18, bottom: 48, left: 44 },
  data: [
    { cat: "Apples", v: 6 },
    { cat: "Pears", v: 9 },
    { cat: "Plums", v: 4 },
  ],
  schema: {
    cat: { type: "categorical", domain: ["Apples", "Pears", "Plums"] },
    v:   { type: "quantitative", domain: [0, 12] },
  },
  axes: false,
  marks: [
    axisY(),
    axisX({ edit: edit.scale.categories() }),
    bar({ fill: "#2563eb",
      channels: { x: { field: "cat" }, y: { field: "v" } } }),
  ],
}))
Try: Double-click ＋ to add a bar · double-click a label to rename · click × to remove.

Grow a Likert scale

mode: 'grow' keeps each band the same width and grows the chart by a step per point added — extend a 5-point scale to 7 without cramming.

mount(Elicit({
  width: 320, height: 240,
  margins: { top: 16, right: 18, bottom: 46, left: 40 },
  data: [
    { step: "1", n: 3 }, { step: "2", n: 6 }, { step: "3", n: 9 },
    { step: "4", n: 5 }, { step: "5", n: 2 },
  ],
  schema: {
    step: { type: "ordinal", domain: ["1", "2", "3", "4", "5"] },
    n:    { type: "quantitative", domain: [0, 12] },
  },
  axes: false,
  marks: [
    axisY(),
    axisX({ edit: edit.scale.categories({ mode: "grow" }) }),
    bar({ fill: "#0ea5e9",
      channels: { x: { field: "step" }, y: { field: "n" } } }),
  ],
}))
Try: Double-click ＋ to add points — the chart widens instead of the bars shrinking · click × to shrink it back.

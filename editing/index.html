Editing — the inverse of encoding

Attach an edit to a channel and a gesture writes that channel back to the data through the same scale. An edit is a descriptor — gesture (drag / click / dblclick), pick (direct / nearest / plane / probe / sweep), when (arbitration), constrain, and guide — with an apply that performs the inversion. Declare edits on a channel (channels.y.edit), at mark level (edits: [...]), or on legends and axes.

API reference

The Edit descriptor

Every edit factory (elicit.edit.*) returns this shape, built by makeEdit. The named factories are presets over it: each fixes a gesture and an apply — the inversion that turns the gesture back into data. apply(ctx) is pure: given the context it returns a datum (direct edit), a full array (whole-dataset edit), or undefined (no-op).

Returns / emits

An Edit. The engine matches gesture + pick, builds an EditContext, then calls apply(ctx). Three more keys — cardinality, inverts and inline — declare what a new edit does to the dataset; see Authoring.

EditContext (ctx)

The object handed to apply(ctx) and when(ctx) — and to custom(fn)'s one argument. It is the gesture already resolved into plot space plus the mark/scale state needed to invert it. Built once per edit invocation in the engine; read it, don’t mutate it.

Options
OptionTypeDefaultDescription
pointer{ x, y }—Pointer position in plot pixels (origin at the plot’s top-left, inside the margins). Invert with ctx.scales.y.invertValue(ctx.pointer.y).
datumobject | undefined—The row being edited. Set for direct/nearest picks; absent for plane creates that append.
indexnumber | null—Index of datum in data. Returning a plain object splices it back at this index.
dataDatum[]—The full current dataset (read-only). Return a new array from apply for whole-dataset edits (create/remove).
scalesScaleMap—Live scales by channel name (ctx.scales.x, .y, …). Each has invertValue(pixel) / encode(value).
channelsResolvedChannel[]—This edit’s governed channels, each { name, field, scale }. Empty when the edit named none (typical for bare custom).
markChannelsobject—The mark’s full channel map (name → ChannelSpec). Use to look up a sibling field the edit didn’t declare.
eventEvent—The raw DOM event (for modifiers like shiftKey). Prefer edit.when for arbitration when you can.
nodeFeatureNode | null—The scene node under the pointer (direct pick), or null on the plane.
valueany—Non-pixel gesture payload — e.g. the typed string from editText’s commit. Undefined for pointer gestures.
schema, width, height——Dataset schema (for minting rows) and the plot’s inner pixel size (for plane-relative geometry like rotate).
Returns / emits

A line-scoped or driver-backed edit sees more — seriesKey, connect, and the driver’s own session. The TypeScript definitions carry the full shape.

Edit catalogue

Universal edits import bare (elicit.edit.move). A scoped family sits under the subject it is about, and that dotted path is also the edit’s type: edit.line.draw() is { type: "line.draw" }.

Returns / emits

See Gestures, Sweep, Existence and each mark’s page for a factory’s own options. There is no edit.face.*: a face is a composite of ordinary marks, so its parameters take the universal edits.

Move a value

The canonical edit: move() inverts the pointer on each positional channel it governs. On a bar's y, a drag rewrites the value.

Drag a value (bars)

y carries edit: move(). The gesture → data path mirrors the data → height encoding.

mount(Elicit({
  width: 380, height: 260,
  margins: { top: 14, right: 14, bottom: 26, left: 30 },
  data: [
    { x: "A", y: 20 }, { x: "B", y: 45 },
    { x: "C", y: 30 }, { x: "D", y: 60 },
  ],
  schema: {
    x: { type: "categorical", domain: ["A", "B", "C", "D"] },
    y: { type: "quantitative", domain: [0, 100] },
  },
  marks: [
    bar({
      fill: "#4f46e5",
      channels: {
        x: { field: "x" },
        y: { field: "y", edit: move() },
      },
    }),
  ],
}))
Try: Drag a bar up or down.

Pick — how an edit finds its target

pick: "direct" uses the mark under the pointer; pick: "nearest" grabs the closest mark within a pixel threshold, so small marks are reachable from nearby empty space. guide: true self-draws the snap ring.

Nearest pick from empty space

A 2D nearest drag: move near a dot to select it, drag from empty space to grab the closest.

mount(Elicit({
  width: 340, height: 240,
  margins: { top: 14, right: 14, bottom: 26, left: 30 },
  data: [{ x: 25, y: 35 }, { x: 55, y: 68 }, { x: 78, y: 30 }],
  schema: {
    x: { type: "quantitative", domain: [0, 100] },
    y: { type: "quantitative", domain: [0, 100] },
  },
  marks: [
    point({
      fill: "#ffffff", stroke: "#334155", strokeWidth: 2,
      size: 10,
      channels: {
        x: { field: "x" },
        y: { field: "y" },
      },
      edits: [ move({ channels: ["x", "y"], pick: "nearest", threshold: 45, guide: true }) ],
    }),
  ],
}))
Try: Drag from anywhere near a dot to grab it.

Handles & affordances

Handles give continuous geometries — curves, envelopes, partition seams, and interval spans — explicit grab targets. They bridge visual clarity and physical affordance: use visible circular grips, enlarged invisible hit targets (handles: 'hit'), or boundary seams. All marks share the same sizing, colour, and hit-testing contract.

API reference

handles

The universal handle contract for continuous geometry — line, area, curve, arc, trend, needle, and a span. Every mark that draws a grip spells these the same way.

Options
OptionTypeDefaultDescription
handlesboolean | "hit"true"hit" keeps the enlarged grab target without drawing a circle. false is neither drawn nor grabbable.
handleSizenumber5Radius in px of the grip and its pointer hitbox.
handleColorstringtheme.handleGrip fill. Falls back to the mark's own ink when the theme names none, so a recoloured mark keeps a matching grip.
Returns / emits

A grip is drawn only where an edit can use it. A mark with no edit on the channel draws none, whatever handles says.

moveSpan(options)

Translate a two-endpoint span — both endpoints move together, so its width is preserved.

moveSpan({ channels, when, stage }) → Edit
Options
OptionTypeDefaultDescription
channels[string, string]injectedThe span pair to govern, e.g. ["x1", "x2"] or ["y1", "y2"].

brushSpan(options)

The Gantt-bar interaction. Grabbing near one endpoint resizes that edge alone; grabbing the body translates both. The zone is resolved once, at the start of the drag.

brushSpan({ channels, edgeInset, guide, when }) → Edit
Options
OptionTypeDefaultDescription
channels[string, string]injectedThe span pair to govern, e.g. ["x1", "x2"] or ["y1", "y2"].
edgeInsetnumber8Catchment width in px at each end: inside it the gesture resizes that edge, outside it moves the whole span.
pick—'brush'Fixed. brushSpan reads a zone only the brush driver sets, so it cannot be repointed at another pick.
Returns / emits

An Edit. Dragging one edge past the other is allowed mid-gesture; the pair is put back in order once, when you let go.

brushRect(options)

The 2-D counterpart: edges, corners and body of a rect, each live or not as you choose.

brushRect({ resize, move, edgeInset, when }) → Edit
Options
OptionTypeDefaultDescription
resize'both' | 'x' | 'y' | 'none''both'Which axes' edges and corners are live. 'none' leaves a pure 2-D move.
movebooleantrueWhether a body drag translates the whole rect. false leaves a resize-only brush.
edgeInsetnumber8Catchment width in px along each edge.
channelsstring[]['x1','x2','y1','y2']The two endpoint pairs it governs.
Returns / emits

An Edit. A disabled zone degrades to the body, so resize: 'x' behaves like a per-axis brushSpan.

edit.stack.edge(options)

Drag an interior boundary to move value between the two segments it separates. The group total is preserved by construction.

Options
OptionTypeDefaultDescription

Visible grips vs. invisible hit targets

Continuous geometries like lines and area fills have no natural individual nodes to grab. Handles supply the grab targets.

handles: true draws visible circular grips on each vertex. handles: 'hit' renders no visible circles, but keeps the enlarged pointer hit targets along the path — keeping editorial charts uncluttered while remaining easy to drag. handles: false disables interaction on that mark.

Invisible hit targets (handles: 'hit')

handles: 'hit' leaves no visible dots, but lets you drag along the top edge.

mount(Elicit({
  width: 380, height: 220,
  margins: { top: 16, right: 16, bottom: 28, left: 34 },
  data: [
    { t: 1, n: 20 }, { t: 2, n: 55 }, { t: 3, n: 35 },
    { t: 4, n: 70 }, { t: 5, n: 45 },
  ],
  schema: {
    t: { type: "quantitative", domain: [1, 5] },
    n: { type: "quantitative", domain: [0, 100] },
  },
  marks: [
    areaY({
      handles: "hit",
      fill: "#3b82f6",
      opacity: 0.7,
      channels: {
        x: { field: "t" },
        y: { field: "n", edit: move() },
      },
    }),
  ],
}));
Try: Drag along the top edge of the area to reshape the distribution.

Boundary seams (arcs & stacked bars)

On partitions and shares, handles appear at the interior boundaries between adjacent slices. An n-slice pie or stacked bar carries n − 1 boundary handles.

edit.stack.edge() lets you drag any interior boundary to redistribute value between the two adjacent slices. The shared total remains constant.

Drag slice boundaries

Each handle pair-shifts adjacent shares while preserving the 100% total.

mount(Elicit({
  width: 300, height: 260,
  margins: { top: 20, right: 20, bottom: 20, left: 20 },
  axes: false,
  data: [
    { source: "Solar", share: 45 },
    { source: "Wind", share: 35 },
    { source: "Hydro", share: 20 },
  ],
  schema: {
    source: { type: "categorical" },
    share: { type: "quantitative", domain: [0, 100] },
  },
  marks: [
    arc({
      outerRadius: 95,
      edits: [edit.stack.edge()],
      channels: {
        theta: { field: "share" },
        fill: { field: "source" },
      },
    }),
  ],
}));
Try: Drag any slice boundary to reallocate share between categories.

Span endpoints & body brushes

On marks with explicit ranges (x1/x2 or y1/y2), handles sit at the span endpoints.

brushSpan() provides two distinct behaviours on one mark: grab near an edge handle to resize just that bound, or grab the middle body to translate the entire span. Dragging the lower handle past the upper handle automatically flips the fields to preserve ordering without visual jumps.

Resize edges or drag span body

Grab within edgeInset pixels to resize an endpoint; grab the centre to slide the task.

mount(Elicit({
  width: 380, height: 220,
  margins: { top: 14, right: 16, bottom: 26, left: 60 },
  data: [
    { task: "Research", start: 2, end: 6 },
    { task: "Design",   start: 4, end: 9 },
    { task: "Build",    start: 7, end: 12 },
  ],
  schema: {
    task:  { type: "categorical", domain: ["Research", "Design", "Build"] },
    start: { type: "quantitative", domain: [0, 14] },
    end:   { type: "quantitative", domain: [0, 14] },
  },
  marks: [
    barX({
      fill: "#2563eb",
      channels: {
        y: { field: "task" },
        x1: { field: "start" },
        x2: { field: "end" },
      },
      edits: [
        brushSpan({
          channels: ["x1", "x2"],
          threshold: 30,
          edgeInset: 12,
          guide: true,
        }),
      ],
    }),
  ],
}));
Try: Drag an end handle to resize · drag the bar body to move the whole range.

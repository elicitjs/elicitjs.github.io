Probe & multi-step stages

The probe flow lets respondents inspect ephemeral proposals before committing: pointer movement renders an uncommitted ghost while getData() reports only the last settled belief. Combining pick: "probe" with numeric stage values enables progressive multi-step elicitation pipelines.

API reference

anyEdit({ pick: "probe", stage, advance })

Not a new edit — a pick you give an existing one. It runs that edit twice. On hover or drag the proposal is parked as a preview and drawn as an inert ghost; on click or dragend the same proposal is committed. The ghost is therefore exactly what a commit writes. Both gestures settle, so a knob can be dragged as well as clicked.

rotate({ pick: "probe", stage: 0 })          // line follows the pointer; click sets it
move({ pick: "probe", advance: false })      // a knob that tracks then settles
create({ pick: "probe", advance: false })    // a tentative dot, made real on click
toggle({ pick: "probe", channels: ["x","y"] })  // preview a cell being (un)picked
Options
OptionTypeDefaultDescription
stagenumbernullActive only in this stage. A click settling it advances the chart to the next stage, freezing the field.
advancebooleantrueSet false so a click commits without advancing — the edit stays live for repeated answers.
Returns / emits

Previews never reach onChange, getData or the belief store; leaving the plot discards the proposal. Constraints run on the preview too, so a rejected value never even previews.

Ephemeral ghost proposals

Setting pick: "probe" on any edit splits interaction into preview and commit. As the cursor moves, marks render an inert ghost showing what a commit would produce.

Because proposals operate on the dataset rather than a single mark, every mark reading those rows reflects the ghost in real time. getData() and onChange remain untouched until commit.

Probe a single value

move({ pick: 'probe' }) displays a ghost knob that settles on click or drag release.

const chart = Elicit({
  width: 380, height: 130,
  margins: { top: 20, right: 24, bottom: 34, left: 24 },
  axes: { x: {}, y: false },
  data: [{ v: 20 }],
  schema: {
    v: { type: "quantitative", domain: [0, 100] },
  },
  constraints: [ clamp({ min: 0, max: 100, field: "v" }) ],
  marks: [
    point({
      id: "belief",
      size: 9, fill: "#2563eb",
      channels: { x: { field: "v",
                       edit: move({ pick: "probe", advance: false }) },},
    }),
  ],
});
mount(chart);
const out = document.createElement("div");
out.style.cssText = "font:12px ui-monospace,monospace;color:#64748b";
const show = () => { out.textContent = "committed: " + chart.getData()[0].v.toFixed(0); };
chart.on("change", show); show();
mount(out);
Try: Move across the track and click — or grab the knob and drag.

Dual commit gestures

pick: "probe" accepts two natural gestures interchangeably:

  1. Move-then-click: Move the pointer without pressing a button to position the ghost, then click to settle.
  2. Grab-and-drag: Press on the mark, drag to the target value, and release.

Multi-step stages (progressive elicitation)

For multi-part questions ("first set the mean, then specify your confidence"), assign a numeric stage to each edit. An edit is active only when its stage matches the chart's current stage.

Edits with pick: "probe" advance to the next stage automatically upon commit. You can also control stages programmatically with chart.nextStage(), chart.setStage(n), and chart.getStage().

Two-step pipeline: slope, then spread

Stage 0 sets the trend slope; stage 1 opens the confidence cone.

const chart = Elicit({
  width: 320, height: 320,
  margins: { top: 20, right: 20, bottom: 20, left: 20 },
  axes: false,
  data: [{ r: 0, spread: 0 }],
  schema: {
    x: { type: "quantitative", domain: [-1, 1] },
    y: { type: "quantitative", domain: [-1, 1] },
    r:      { type: "quantitative", domain: [-1, 1] },
    spread: { type: "quantitative", domain: [0, 1] },
  },
  marks: [
    trendBand({
      render: "samples", samples: 60,
      channels: {
        intercept:   { datum: 0 },
        slope:       { field: "r" },
        slopeSpread: { field: "spread" },
      },
    }),
    trend({
      id: "belief",
      handles: false,
      stroke: "#d33", strokeWidth: 3,
      channels: {
        intercept: { datum: 0 },
        // Stage 0: no handle to grab, so the gesture takes the pointer's own x
        // and the line simply follows the cursor. A click sets it and advances.
        slope: { field: "r", edit: edit.trend.slope({ pick: "probe", stage: 0 }) },
        // Stage 1: how far the line through the pointer tilts away from the
        // committed one is the envelope half-width.
        slopeSpread: { field: "spread", edit: edit.trend.slopeSpread({ pick: "probe", stage: 1 }) },
      },
    }),
  ],
});
mount(chart);
const out = document.createElement("div");
out.style.cssText = "font:12px ui-monospace,monospace;margin-top:6px;color:#64748b";
const show = () => {
  const d = chart.getData()[0] || {};
  out.textContent = "stage " + chart.getStage() +
    "  ·  committed r=" + (d.r ?? 0).toFixed(2) + " spread=" + (d.spread ?? 0).toFixed(2);
};
chart.on("change", show); chart.on("stage", show); show();
mount(out);
Try: Move the mouse to aim the line and click; then move to open the confidence cone and click.

Progression via nextStage()

Stage 0 moves position along x; stage 1 resizes the magnitude.

const chart = Elicit({
  width: 380, height: 240,
  margins: { top: 16, right: 16, bottom: 28, left: 16 },
  axes: { x: {}, y: false },
  stage: 0,
  data: [{ x: 5, mag: 12 }],
  onChange: (d) => console.log(d[0]),
  schema: {
    x:   { type: "quantitative", domain: [0, 10] },
    mag: { type: "quantitative", domain: [0, 14] },
  },
  marks: [
    point({
      channels: {
        x: { field: "x", edit: move({ stage: 0 }) },
        size: { field: "mag", edit: resize({ stage: 1 }) },
      },
    }),
  ],
});
mount(chart);
const label = document.createElement("div");
const render = () => { label.textContent = "stage: " + chart.getStage(); };
chart.on("stage", render); render();
const btn = document.createElement("button");
btn.textContent = "Next";
btn.onclick = () => chart.nextStage();
const controls = document.createElement("div");
controls.style.cssText = "margin-top:8px;display:flex;gap:10px;align-items:center";
controls.append(btn, label);
mount(controls);
Try: Drag horizontally, click Next, then drag outward to resize.

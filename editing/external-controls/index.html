External controls

Bind an edit to any external controller — a <select>, sliders, a rotate icon, a plain function — and drive it from outside the SVG. Give the edit a name, then call el.control(name).set(value). Nothing about how edits work changes: the control synthesizes the same events a pointer produces and hands them to the one dispatch, so constraints, undo/redo, guides, and on("change") all run identically. It is a new input source, not a second interaction system — the same move the keyboard already makes when it turns an arrow key into a drag.

API reference

edit({ name }) · container.control(name, index?)

Give any edit a name, then drive it from outside the chart with el.control(name). The control synthesizes the same events a pointer does and feeds them to the one dispatch — so constraints, undo, guides, and on("change") all run. A new input source, not a second interaction system.

move({ name: "move", channels: ["x", "y"] })   // name an edit
const h = el.control("move", 0);   // handle bound to the edit + datum 0
h.set(value)          // one-shot write (value edit) …
h.set({ x, y })       // … or a data value per channel (positional edit)
h.begin(); h.set(v); h.end();   // live drag → ONE undo entry
h.fire()              // TRIGGER edit (cycle/remove/toggle) — fires its click gesture
h.emit(event)         // raw event passthrough, scoped to this feature/node
h.accepts()           // what the channel's scale allows
Options
OptionTypeDefaultDescription
edit.namestringnullThe handle this edit answers to. An edit with no name stays pointer- and keyboard-driven.
control(name, index?)→ EditControlindex: 0A handle bound to that edit and that row. Ask for it again after the data changes; it resolves the edit on each call.
h.set(value)void—Write a data value. A scalar for a single-channel edit, or a map keyed by channel or field for a multi-channel one. Untouched axes hold their current position rather than teleporting.
h.begin() / h.end()void—Bracket a live drag, so many set ticks collapse into one undo entry — exactly as a pointer drag does.
h.fire()void—Trigger an edit that takes no value — cycle, remove, toggle. It dispatches the edit’s own gesture on the row.
h.accepts()→ object | null—What the channel’s scale allows: { field, type, kind, temporal, invertible, domain, values, range }. values is the accepted set on a discrete channel and null on a continuous one, where domain is the accepted range — so a picker or slider can offer only valid choices.
h.emit(event)void—A raw event, scoped to this edit's feature and node. The low-level route when you already hold pixels.
Returns / emits

Every route runs the ordinary dispatch, so a constraint gates an external write exactly as it gates a drag. External control is not a bypass.

set(options?)

The universal value edit: write a value into a channel's field — quantitative, colour, categorical, temporal. The commit-gesture counterpart to the positional edits, and what an external picker/slider drives via control(name).set(value). (editText is its text specialization.)

fill: { field: "group", edit: set({ name: "category" }) }
el.control("category", i).set("B")

select() · el.select · el.selectWhere

Selection is transient pipeline state, not a selected data column. Put edit.select() on a mark to select it by click; drive the same state from outside with el.select(index) (a specific item) or el.selectWhere(field, value) (a category — the first matching row). The selected row gets the highlight outline, and a legend picker's row defaults to it. A select event fires; on("change")/getData never do.

edits: [ select() ]            // click a mark to select it
el.select(2)                   // select a SPECIFIC item by index
el.selectWhere("group", "North")  // select by CATEGORY (first match)
el.getSelection()             // → index | null
el.clearSelection()           // deselect all
el.on("select", (i, all) => …)  // selection changed (no data moved)

container.emit(event)

Low-level: inject a renderer-shaped gesture event directly. x/y are inner (margin-subtracted) pixels. Prefer control, which computes pixels from a data value for you.

el.emit({ type: "commit", node, value })
el.emit({ type: "dragstart", node });  el.emit({ type: "drag", node, x, y });  el.emit({ type: "dragend", node })

Name an edit, then drive it

The value flows the opposite way through the same scale. An edit maps a gesture → data by inverting a channel's scale; control(name).set(value) maps data → a gesture by running that scale forward, then dispatches the ordinary edit. For a value edit (set/editText) there is no pixel at all — the value is carried straight through. control(name).accepts() reports what the channel's scale allows, so a picker or slider can offer only valid values.

A picker and a drag pad

The <select> writes the point's category through a set() edit; its options come from control("category", 0).accepts().values. The pad drives a two-axis move live — begin() … set({x,y}) … end() collapses into one undo entry. The clamp on y gates the pad exactly as it gates a mouse drag: external control is not a bypass.

Scatter: category picker + drag pad

A <select> sets the category; a draggable pad moves the point through the clamped drag edit.

// External controllers drive the SAME edits a pointer does. A `<select>` sets the
// category (a value edit); a draggable pad moves the point (a positional edit).
// Both go through the normal pipeline — the clamp on y holds for the pad exactly
// as it would for a mouse drag.
const chart = Elicit({
  width: 380, height: 260,
  margins: { top: 14, right: 14, bottom: 26, left: 30 },
  schema: {
    x:     { type: "quantitative", domain: [0, 100] },
    y:     { type: "quantitative", domain: [0, 100] },
    group: { type: "categorical",  domain: ["A", "B", "C"] },
  },
  data: [
    { x: 30, y: 40, group: "A" },
    { x: 62, y: 70, group: "B" },
    { x: 78, y: 25, group: "C" },
  ],
  // A dataset invariant: y can never exceed 80. It gates EVERY edit, including the
  // pad drag below — external control is not a bypass.
  constraints: [ clamp({ field: "y", max: 80 }) ],
  marks: [
    point({
      size: 7,
      channels: {
        x: { field: "x" },
        y: { field: "y" },
        fill: {
          field: "group",
          scale: { range: ["#2563eb", "#059669", "#d97706"] },
          // A universal value edit: an external picker writes the chosen category.
          edit: set({ name: "category" }),
        },
      },
      // One drag over BOTH axes, named so a controller can address it.
      edits: [ move({ name: "move", channels: ["x", "y"] }) ],
    }),
  ],
});
mount(chart);

// We drive datum 0 (the first point). `.accepts()` reads what the channel allows.
const i = 0;
const cats = chart.control("category", i).accepts().values;   // ["A","B","C"]
const [dx, dy] = [chart.getSchema().x.domain, chart.getSchema().y.domain];

const controls = document.createElement("div");
controls.style.cssText = "display:flex;gap:16px;align-items:center;margin-top:10px;font:12px system-ui";

// 1) Category picker — options come straight from the scale's accepted values.
const pick = document.createElement("select");
for (const c of cats) {
  const o = document.createElement("option");
  o.value = c; o.textContent = c; pick.append(o);
}
pick.value = chart.getData()[i].group;
pick.onchange = () => chart.control("category", i).set(pick.value);
const pickWrap = document.createElement("label");
pickWrap.style.cssText = "display:flex;gap:6px;align-items:center";
pickWrap.append("category", pick);

// 2) A draggable pad — the "UI element around the point". Dragging maps the pad's
// local position to data space and drives the `move` edit live: begin() … set() …
// end() collapse into ONE undo entry, just like a real drag.
const pad = document.createElement("div");
pad.style.cssText = "position:relative;width:120px;height:120px;border:1px solid #cbd5e1;border-radius:8px;background:#f8fafc;touch-action:none;cursor:grab";
const knob = document.createElement("div");
knob.style.cssText = "position:absolute;width:14px;height:14px;margin:-7px 0 0 -7px;border-radius:50%;background:#111827";
pad.append(knob);
const placeKnob = () => {
  const d = chart.getData()[i];
  knob.style.left = ((d.x - dx[0]) / (dx[1] - dx[0]) * 100) + "%";
  knob.style.top = (100 - (d.y - dy[0]) / (dy[1] - dy[0]) * 100) + "%";
};
let handle = null;
const toData = (ev) => {
  const r = pad.getBoundingClientRect();
  const fx = Math.max(0, Math.min(1, (ev.clientX - r.left) / r.width));
  const fy = Math.max(0, Math.min(1, (ev.clientY - r.top) / r.height));
  return { x: dx[0] + fx * (dx[1] - dx[0]), y: dy[0] + (1 - fy) * (dy[1] - dy[0]) };
};
pad.addEventListener("pointerdown", (ev) => {
  pad.setPointerCapture(ev.pointerId);
  handle = chart.control("move", i);
  handle.begin();
  handle.set(toData(ev));
});
pad.addEventListener("pointermove", (ev) => { if (handle) handle.set(toData(ev)); });
const stop = () => { if (handle) { handle.end(); handle = null; } };
pad.addEventListener("pointerup", stop);
pad.addEventListener("pointercancel", stop);

const padWrap = document.createElement("div");
padWrap.style.cssText = "display:flex;flex-direction:column;gap:4px;align-items:center;color:#64748b";
padWrap.append(pad, document.createTextNode("drag to move point 0"));

controls.append(pickWrap, padWrap);
mount(controls);

// Keep the picker + knob in sync with committed data (edits, undo, redo all fire).
chart.on("change", () => { pick.value = chart.getData()[i].group; placeKnob(); });
placeKnob();
Try: pick a category; drag the pad; the point obeys the y ≤ 80 clamp either way.

Pick vs. cycle: driving other gestures

.set(value) covers the value edits (set/editText) and the positional ones (move/rotate/resize). The click-triggered edits — cycle, remove, toggle — take no value; they just fire. .fire() drives those, dispatching the edit's own gesture on the datum. So one circle can offer a picker (set — jump straight to a value) and a cycle (fire — step to the next), on the same field, alongside the native click.

A circle: pick or cycle its category

A dropdown sets the category (set); a button and the circle itself step it (cycle).

// Two ways to change one circle's category, both external. `cycle` is a CLICK edit
// that steps to the next value; a picker SETS a value directly. They coexist on the
// same `fill` field: click the circle (or the ⟳ button) to step, or choose from the
// dropdown to jump straight there.
const chart = Elicit({
  width: 300, height: 190,
  margins: { top: 10, right: 10, bottom: 10, left: 10 },
  schema: {
    kind: { type: "categorical", domain: ["low", "med", "high"] },
  },
  data: [ { kind: "low" } ],
  marks: [
    point({
      size: 26,
      channels: {
        x: { value: 150 },
        y: { value: 90 },
        fill: {
          field: "kind",
          scale: { range: ["#93c5fd", "#3b82f6", "#1e3a8a"] },
          // Direct choice — a picker writes exactly this value.
          edit: set({ name: "pick" }),
        },
      },
      // Step-at-a-time — a click (on the circle or a button) advances the category.
      edits: [ cycle({ name: "step", channel: "fill" }) ],
    }),
  ],
});
mount(chart);

const controls = document.createElement("div");
controls.style.cssText = "display:flex;gap:12px;align-items:center;margin-top:10px;font:13px system-ui";

// A picker → `set`: options are exactly the values the fill scale accepts.
const pick = document.createElement("select");
for (const v of chart.control("pick", 0).accepts().values) {
  const o = document.createElement("option");
  o.value = v; o.textContent = v; pick.append(o);
}
pick.value = chart.getData()[0].kind;
pick.onchange = () => chart.control("pick", 0).set(pick.value);
const pickWrap = document.createElement("label");
pickWrap.style.cssText = "display:flex;gap:6px;align-items:center";
pickWrap.append("pick", pick);

// A button → `fire`: dispatches the cycle edit's own click gesture, no value.
const step = document.createElement("button");
step.textContent = "⟳ cycle";
step.onclick = () => chart.control("step", 0).fire();

controls.append(pickWrap, step);
mount(controls);

// Keep the picker in step whichever way the category changed.
chart.on("change", () => { pick.value = chart.getData()[0].kind; });
Try: choose from the dropdown, press ⟳, or click the circle — all change the same field.

Sliders for facial features

Each facial parameter is a channel; bind it to a field with a named set() edit and a slider can write it — while the face stays directly draggable (grab the mouth, pull a smile). One dataset, two input sources, the same edits. Each slider's range comes from control(field).accepts().domain.

Face: parameter sliders

Three sliders drive three facial params; dragging the face keeps them in sync.

// A face is a row of fields; each facial PARAM is a channel on one of the face's
// parts. Bind each to a field with a named `set()` edit and an external slider can
// write it. `.accepts()` reads the range off the very scale the part encodes
// through — including a group's per-datum FRAME scale — so the slider offers
// exactly the values the channel accepts. Add a `slide`/`rotate` alongside and the
// same field is drivable by pointer too: one dataset, two input sources.
const PARAMS = [
  { param: "mouthCurve", field: "smile", label: "smile" },
  { param: "eyeScale",   field: "eyes",  label: "eyes"  },
  { param: "browTilt",   field: "brow",  label: "brow"  },
];

const channels = {};
for (const { param, field } of PARAMS) {
  channels[param] = { field, edit: set({ name: field }) };
}

const chart = Elicit({
  width: 300, height: 300,
  margins: { top: 12, right: 12, bottom: 12, left: 12 },
  schema: {
    smile: { type: "quantitative", domain: [0, 1] },
    eyes:  { type: "quantitative", domain: [0, 1] },
    brow:  { type: "quantitative", domain: [0, 1] },
  },
  data: [ { smile: 0.7, eyes: 0.5, brow: 0.4 } ],
  marks: [ face({ channels }) ],
});
mount(chart);

const controls = document.createElement("div");
controls.style.cssText = "display:flex;flex-direction:column;gap:8px;margin-top:10px;font:12px system-ui;max-width:300px";

const sliders = {};
for (const { field, label } of PARAMS) {
  // `.accepts()` tells the UI the field's range (from the scale/schema), so the
  // slider offers only values the channel accepts.
  const [lo, hi] = chart.control(field).accepts().domain;
  const row = document.createElement("label");
  row.style.cssText = "display:grid;grid-template-columns:48px 1fr;gap:8px;align-items:center";
  const s = document.createElement("input");
  s.type = "range"; s.min = lo; s.max = hi; s.step = (hi - lo) / 100;
  s.value = chart.getData()[0][field];
  s.oninput = () => chart.control(field).set(+s.value);
  sliders[field] = s;
  row.append(label, s);
  controls.append(row);
}
mount(controls);

// Dragging the face directly also fires `change` — keep the sliders in step.
chart.on("change", () => {
  const d = chart.getData()[0];
  for (const { field } of PARAMS) sliders[field].value = d[field];
});
Try: move a slider, or drag the face directly — both write the same fields.

A rotate icon for a box

rotate reads a pointer angle about the mark; driving it by degrees is the inverse. control("spin", 0).set(deg) forward-encodes the angle to the pointer that would produce it, then runs the ordinary rotate edit. The box also rotates by direct drag.

Rotate a box by an icon

Buttons step the angle in data space; the façade forward-encodes to the rotate edit.

// A rotate icon spins a box. `rotate` is a positional edit — it reads a pointer
// angle about the mark. Driving it by a DATA value (degrees) is just the inverse:
// `.set(deg)` forward-encodes the angle to the pointer that would produce it, then
// runs the ordinary edit. The box is also directly rotatable by dragging it.
const chart = Elicit({
  width: 300, height: 260,
  margins: { top: 20, right: 20, bottom: 20, left: 20 },
  schema: {
    x:     { type: "quantitative", domain: [0, 100] },
    y:     { type: "quantitative", domain: [0, 100] },
    theta: { type: "quantitative", domain: [0, 360] },
  },
  data: [ { x: 50, y: 50, theta: 20 } ],
  marks: [
    rect({
      channels: {
        x: { field: "x" },
        y: { field: "y" },
        width:  { value: 90 },
        height: { value: 60 },
        fill: { value: "#6366f1" },
        stroke: { value: "#3730a3" },
        angle: {
          field: "theta",
          scale: { range: [0, 360] },
          edit: rotate({ name: "spin", pick: "direct", pivot: "mark", fold: false }),
        },
      },
    }),
  ],
});
mount(chart);

const controls = document.createElement("div");
controls.style.cssText = "display:flex;gap:8px;align-items:center;margin-top:10px;font:13px system-ui";

const spinBy = (delta) => {
  const now = chart.getData()[0].theta;
  const next = ((now + delta) % 360 + 360) % 360;
  chart.control("spin", 0).set(next);   // forward-encodes deg -> pointer -> rotate
};

const ccw = document.createElement("button");
ccw.textContent = "⟲ −15°";
ccw.onclick = () => spinBy(-15);
const cw = document.createElement("button");
cw.textContent = "⟳ +15°";
cw.onclick = () => spinBy(15);

const readout = document.createElement("span");
readout.style.cssText = "color:#64748b";
const sync = () => { readout.textContent = Math.round(chart.getData()[0].theta) + "°"; };
chart.on("change", sync);
sync();

controls.append(ccw, cw, readout);
mount(controls);
Try: press the rotate buttons, or drag the box itself.

Driving the selection

Selection is pipeline state, not a data column — so it has its own external API beside getData/setData, and its own select event. el.select(index) picks a specific item; el.selectWhere(field, value) picks by category (the first row matching, or every one with { all: true }). Both go through the same path a click on a mark does (edit.select()), so the selected row gets the highlight outline and a legend picker edits it — whichever input moved the selection. on("select") reports the change; getData and on("change") stay silent, because no belief data moved.

Pass an array to el.select for several rows at once. See Selection for the whole model — multi-select, the selected effect, and the edits that read it.

Select an item, or a category

A dropdown selects a specific bar; a button selects the first bar in a group; the legend edits whichever is selected.

// Selection is pipeline state, so it has its own external API beside the data —
// no `selected` column. `el.select(index)` picks a SPECIFIC ITEM; `el.selectWhere`
// picks by CATEGORY (the first row matching a field/value). Clicking a bar selects
// it too (edit.select), and `on("select")` reports whichever way it moved. The
// legend then edits the SELECTED bar's group.
const chart = Elicit({
  width: 360, height: 210,
  margins: { top: 16, right: 16, bottom: 28, left: 36 },
  data: [
    { name: "A", value: 12, group: "North" },
    { name: "B", value: 8,  group: "South" },
    { name: "C", value: 15, group: "North" },
    { name: "D", value: 6,  group: "South" },
  ],
  schema: {
    name: { type: "categorical", domain: ["A", "B", "C", "D"] },
    group: { type: "categorical", domain: ["North", "South"] },
    value: { type: "quantitative", domain: [0, 16] },
  },
  marks: [
    barY({
      channels: {
        x: { field: "name" },
        y: { field: "value" },
        fill: { field: "group" },
      },
      edits: [ select() ],           // click a bar to select it
    }),
    legendColor({ anchor: "right", title: "group", edit: edit.legend.category() }),
  ],
});
mount(chart);

const controls = document.createElement("div");
controls.style.cssText = "display:flex;gap:12px;align-items:center;flex-wrap:wrap;margin-top:10px;font:13px system-ui";

// Select a SPECIFIC ITEM by its name (→ el.selectWhere on the `name` field).
const item = document.createElement("select");
for (const d of chart.getData()) {
  const o = document.createElement("option");
  o.value = d.name; o.textContent = d.name; item.append(o);
}
item.onchange = () => chart.selectWhere("name", item.value);
const itemWrap = document.createElement("label");
itemWrap.style.cssText = "display:flex;gap:6px;align-items:center";
itemWrap.append("item", item);

// Select a CATEGORY — the first bar in a group (→ el.selectWhere on `group`).
const cat = document.createElement("select");
for (const g of ["North", "South"]) {
  const o = document.createElement("option");
  o.value = g; o.textContent = g; cat.append(o);
}
const catBtn = document.createElement("button");
catBtn.textContent = "select group";
catBtn.onclick = () => chart.selectWhere("group", cat.value);
const catWrap = document.createElement("label");
catWrap.style.cssText = "display:flex;gap:6px;align-items:center";
catWrap.append("group", cat, catBtn);

// Clear.
const clear = document.createElement("button");
clear.textContent = "clear";
clear.onclick = () => chart.clearSelection();

const readout = document.createElement("span");
readout.style.cssText = "margin-left:auto;color:#6b7280";

controls.append(itemWrap, catWrap, clear, readout);
mount(controls);

// on("select") hears selection changes — never `change`, since no data moved.
chart.on("select", (i) => {
  const d = i == null ? null : chart.getData()[i];
  readout.textContent = d ? `selected: ${d.name} (${d.group})` : "nothing selected";
  if (d) item.value = d.name;
});
readout.textContent = "nothing selected";
Try: pick an item or a group — or click a bar — then use the legend to change its group.

Row lifecycle & lock

Manage dataset membership and permissions. create() inverts clicked pixels to append new rows, remove() deletes rows on modifier clicks, and lock protects given ground truth from accidental edits.

API reference

create(options)

A plane gesture that mints a datum — inverts pointer pixels through positional channels, populating defaults for the rest.

create({ channels, defaults, gesture }) → Edit
Options
OptionTypeDefaultDescription
channelsstring[]['x','y']Positional channels to place from the pointer.
defaultsobject{}Seed values for non-positional fields on newly minted rows.
gesture'click' | 'dblclick''click'The plane gesture that triggers creation.

remove(options)

Deletes the targeted datum from the dataset.

remove({ pick, threshold, when, gesture }) → Edit
Options
OptionTypeDefaultDescription
when(ctx) => boolean—Arbitration predicate (e.g. when.alt so Alt-click deletes while click recolours).
gesturestring'click'The gesture that removes the row.

lock

Marks seed rows or matching rows as read-only, preventing edits and deletion.

lock: 'seed' | ((datum) => boolean)
Options
OptionTypeDefaultDescription
lock: 'seed''seed'Locks all initially supplied rows; newly created rows remain editable.
lock: (d) => booleanFunctionPredicate function locking specific rows by field (e.g. d.kind === 'actual').

What can — and cannot — be created

Creation writes dataset rows, so it belongs on a data mark positioned by an invertible axis. Only guides (which have no per-row data) and derived marks (computed from the whole dataset, like trend) are excluded.

MarkCreate?How
point · dot · symbol✓Invert pointer through x and y
tick · bar✓One axis inverts to a band slot, the other to value
rect✓Seed default extents (x1/x2 or y1/y2)
composite (glyph)✓Create on one component mark; row renders across all
line · path✓Series-aware anchor and draw edits
rule · axis · grid✗Guides edit the domain schema, not data rows
trend✗Derived regression fit over all rows

Create — click to add

create() listens on empty space to invert pointer coordinates and append a new row. Constraints (such as count({ max })) cap the total allowed dataset size.

Declare a creator on exactly one mark so a single click mints one row.

Click to add a point

create({ defaults }) mints a datum at the pointer; count({ max: 8 }) caps the dataset.

mount(Elicit({
  width: 380, height: 260,
  margins: { top: 14, right: 14, bottom: 26, left: 30 },
  data: [{ x: 30, y: 30, group: "a" }],
  schema: {
    // Declared so create() mints it on a new row — an undeclared column would be
    // missing from every point the click adds.
    group: { type: "categorical" },
    x: { type: "quantitative", domain: [0, 100] },
    y: { type: "quantitative", domain: [0, 100] },
  },
  constraints: [ count({ max: 8 }) ],   // dataset invariant: at most 8
  marks: [
    point({
      fill: "#0d9488",
      size: 8,
      channels: {
        x: { field: "x", edit: move() },
        y: { field: "y", edit: move() },
      },
      edits: [ create({ defaults: { group: "a" } }) ],
    }),
  ],
}))
Try: Click empty space to add a point · drag to move it.

Create, move & remove arbitration

When multiple edits share a mark, use when predicates to separate gestures (e.g. double-click to add, drag to move, Alt+click to remove).

Create, move, and remove on one mark

Double-click adds, Alt-click deletes, and drag moves.

mount(Elicit({
  width: 380, height: 260,
  margins: { top: 14, right: 14, bottom: 26, left: 30 },
  data: [{ x: 30, y: 40 }, { x: 65, y: 65 }],
  schema: {
    s: { type: "categorical" },  // the series key; declared so create() mints it
    x: { type: "quantitative", domain: [0, 100] },
    y: { type: "quantitative", domain: [0, 100] },
  },
  marks: [
    point({
      fill: "#0d9488",
      size: 8,
      channels: {
        x: { field: "x" },
        y: { field: "y" },
      },
      edits: [
        move({ channels: ["x", "y"] }),
        create({ gesture: "dblclick" }),
        remove({ when: when.alt }),
      ],
    }),
  ],
}))
Try: Double-click to add · Alt+click to delete · Drag to move.

Arbitration between click actions

when.noAlt cycles color; when.alt removes the row.

mount(Elicit({
  width: 380, height: 260,
  margins: { top: 14, right: 14, bottom: 26, left: 30 },
  data: [
    { x: 25, y: 40, group: "alpha" },
    { x: 55, y: 65, group: "beta" },
    { x: 80, y: 30, group: "gamma" },
  ],
  schema: {
    s: { type: "categorical" },  // the series key; declared so create() mints it
    x:     { type: "quantitative", domain: [0, 100] },
    y:     { type: "quantitative", domain: [0, 100] },
    group: { type: "categorical", domain: ["alpha", "beta", "gamma"] },
  },
  marks: [
    point({
      size: 10,
      channels: {
        x: { field: "x", edit: move() },
        y: { field: "y", edit: move() },
        fill: { field: "group", edit: cycle({ when: when.noAlt }) },
      },
      edits: [ remove({ when: when.alt }) ],
    }),
  ],
}))
Try: Click a dot to recolour · Alt+click to delete.

Locked seed data, free additions

Some dataset rows are baseline facts rather than elicited beliefs. Setting lock: "seed" locks all initially supplied rows as read-only. Any row added through create() remains fully editable.

Observed points + elicited additions

Grey points are locked seed data; new additions are interactive.

mount(Elicit({
  width: 400, height: 280,
  margins: { top: 16, right: 16, bottom: 32, left: 40 },
  schema: {
    x: { type: "quantitative", domain: [0, 10] },
    y: { type: "quantitative", domain: [0, 10] },
    source: { type: "categorical", domain: ["observed", "yours"], default: "yours" },
  },
  data: [
    { x: 1.2, y: 2.4, source: "observed" },
    { x: 2.6, y: 3.1, source: "observed" },
    { x: 3.4, y: 4.6, source: "observed" },
    { x: 4.1, y: 4.2, source: "observed" },
    { x: 5.3, y: 6.0, source: "observed" },
  ],
  lock: "seed",
  axes: { x: { grid: true }, y: { grid: true } },
  marks: [
    point({
      size: 7,
      channels: {
        x: { field: "x" },
        y: { field: "y" },
        fill: {
          field: "source",
          scale: { range: ["#94a3b8", "#4f46e5"] },
        },
      },
      edits: [
        create({ when: when.noAlt }),
        move({ channels: ["x", "y"] }),
        remove({ when: when.alt }),
      ],
    }),
  ],
}));
Try: Click empty space to add a point · drag your point. Grey seed points never move.

Locking rows by predicate

Pass a predicate function to lock rows based on their fields (for example, separating historical actuals from future forecasts).

Actuals and forecast in one dataset

lock: (d) => d.kind === "actual" locks Q1 and Q2 while keeping Q3 and Q4 editable.

mount(Elicit({
  width: 400, height: 260,
  margins: { top: 16, right: 16, bottom: 30, left: 44 },
  schema: {
    q:    { type: "categorical",  domain: ["Q1", "Q2", "Q3", "Q4"] },
    n:    { type: "quantitative", domain: [0, 100] },
    kind: { type: "categorical",  domain: ["actual", "forecast"] },
  },
  data: [
    { q: "Q1", n: 42, kind: "actual" },
    { q: "Q2", n: 55, kind: "actual" },
    { q: "Q3", n: 50, kind: "forecast" },
    { q: "Q4", n: 50, kind: "forecast" },
  ],
  lock: (d) => d.kind === "actual",
  marks: [
    barY({
      channels: {
        x: { field: "q" },
        y: { field: "n", edit: move({ guide: true }) },
        fill: {
          field: "kind",
          scale: { range: ["#94a3b8", "#4f46e5"] },
        },
      },
    }),
  ],
}));
Try: Drag Q3 or Q4 (blue). Q1 and Q2 are reported actuals and remain fixed.

You draw it (locked record + multi-stage reveal)

In the classic New York Times "You Draw It" paradigm (e.g. 1968–1990 actuals vs. 1991–2016 predictions):

  1. lock: "seed" locks historical data so dragging over the given years cannot change them.
  2. edit.line.draw({ stage: 0 }) enables drawing the missing years during stage 0.
  3. chart.nextStage() advances to stage 1, retiring the edit and displaying the answer key guide.

Draw the line for the missing years

The historical line (1968–1990) is locked. Draw 1991–2016, then advance the stage to reveal the true record.

// U.S. motor-vehicle deaths per year (NHTSA/FARS, rounded).
// 1968-1990 is the record; the rest is what you believe happened.
const record = [
  [1968, 52725], [1969, 53543], [1970, 52627], [1971, 52542],
  [1972, 54589], [1973, 54052], [1974, 45196], [1975, 44525],
  [1976, 45523], [1977, 47878], [1978, 50331], [1979, 51093],
  [1980, 51091], [1981, 49301], [1982, 43945], [1983, 42589],
  [1984, 44257], [1985, 43825], [1986, 46087], [1987, 46390],
  [1988, 47087], [1989, 45582], [1990, 44599],
].map(([year, deaths]) => ({ year, deaths }));

const truth = [
  [1991, 41508], [1992, 39250], [1993, 40150], [1994, 40716],
  [1995, 41817], [1996, 42065], [1997, 42013], [1998, 41501],
  [1999, 41717], [2000, 41945], [2001, 42196], [2002, 43005],
  [2003, 42884], [2004, 42836], [2005, 43510], [2006, 42708],
  [2007, 41259], [2008, 37423], [2009, 33883], [2010, 32999],
  [2011, 32479], [2012, 33782], [2013, 32893], [2014, 32744],
  [2015, 35485], [2016, 37806],
].map(([year, deaths]) => ({ year, deaths }));

const chart = mount(Elicit({
  width: 560, height: 340,
  margins: { top: 20, right: 24, bottom: 32, left: 56 },
  schema: {
    year:   { type: "quantitative", domain: [1968, 2016] },
    deaths: { type: "quantitative", domain: [0, 60000] },
  },
  data: record,
  lock: "seed",
  axes: {
    x: { tickFormat: "d",  grid: true },
    y: { tickFormat: "~s", grid: true },
  },
  stageLabels: ["draw", "revealed"],
  guides: [
    guides.region({ x: [1968, 1990], fill: "#94a3b8", opacity: 0.12 }),
    guides.custom(({ data, scales }) => [1968, 1990]
      .map((y) => data.find((d) => d.year === y))
      .filter(Boolean)
      .map((d) => ({
        type: "text", text: d3.format(",")(d.deaths),
        x: scales.x.encode(d.year), y: scales.y.encode(d.deaths) - 12,
        fontSize: 12, textAnchor: "middle", fill: "#0f172a",
      }))),
    guides.custom(({ scales, stage }) => stage < 1 ? [] : [{
      type: "path", fill: "none", stroke: "#e8833a", strokeWidth: 2.5,
      points: truth.map((d) => [scales.x.encode(d.year),
                                scales.y.encode(d.deaths)]),
    }]),
  ],
  marks: [
    lineY({
      stroke: "#7f9dc9", strokeWidth: 3, curve: "catmullRom", handleSize: 3,
      channels: {
        x: { field: "year" },
        y: { field: "deaths" },
      },
      edits: [ edit.line.draw({ samples: d3.range(1991, 2017), stage: 0 }) ],
    }),
  ],
}));

const btn = mount(document.createElement("button"));
btn.textContent = "Show me how I did";
btn.onclick = () => chart.nextStage();
Try: Drag across the empty half to draw 1991–2016, then press Show me how I did to reveal the answer key.

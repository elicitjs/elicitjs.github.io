Legend pickers & editing

Legends are active input controls as well as visual keys. Click a swatch to set a categorical field, drag a ramp handle to set a continuous value, or double-click to modify the scale domain itself. When a chart contains multiple rows, pickers write to the active selection automatically.

API reference

edit.legend.category()

Turn legend swatches into click targets that set a categorical field on target rows.

edit.legend.category(options?)
Options
OptionTypeDefaultDescription
rownumber | number[] | Functionchart selection (or row 0 for 1-row data)Which row or rows to update when a swatch is clicked. Defaults to the current selection.

edit.legend.value()

Add a draggable handle to a continuous gradient colour ramp.

edit.legend.value(options?)
Options
OptionTypeDefaultDescription
rownumber | Function0Target row whose numeric value is updated when dragging the ramp handle.

edit.scale.categories()

Inline add, rename, and remove affordances for the scale domain.

edit.scale.categories(options?)
Options
OptionTypeDefaultDescription
mode"rescale" | "grow""rescale""rescale" compresses items to keep chart size fixed; "grow" widens the chart when categories are added.

Categorical swatch pickers

Pass edit: edit.legend.category() to make each legend swatch a click target. Clicking a swatch sets the channel's encoded field on the target row and recolours the mark.

Click a swatch to set category

A one-row belief whose category is updated directly from the legend.

mount(Elicit({
  width: 340, height: 200,
  margins: { top: 20, right: 16, bottom: 20, left: 20 },
  axes: false,
  data: [ { status: "Active" } ],
  schema: {
    status: { type: "categorical", domain: ["Active", "Paused", "Archived"] },
  },
  marks: [
    point({
      size: 40,
      channels: {
        x: { value: 100 },
        y: { value: 100 },
        fill: { field: "status" },
      },
    }),
    legendColor({
      anchor: "right",
      edit: edit.legend.category(),
    }),
  ],
}));
Try: Click a swatch to change the status.

Targeting selected rows

When a dataset has multiple rows, a legend picker needs to know which row to write. The picker's row target defaults to the selection, so clicking a mark and then clicking a swatch updates exactly that mark.

With edit.select({ multi: true }), one swatch click updates every selected row at once.

Select bars, then pick a group

Click a bar to select it (or Shift-click for multiple), then click a swatch to reassign its group.

mount(Elicit({
  width: 380, height: 220,
  margins: { top: 20, right: 16, bottom: 30, left: 40 },
  data: [
    { name: "A", value: 12, group: "North" },
    { name: "B", value: 8,  group: "South" },
    { name: "C", value: 15, group: "East"  },
    { name: "D", value: 6,  group: "West"  },
  ],
  schema: {
    name: { type: "categorical", domain: ["A", "B", "C", "D"] },
    group: { type: "categorical", domain: ["North", "South", "East", "West"] },
    value: { type: "quantitative", domain: [0, 16] },
  },
  marks: [
    barY({
      channels: {
        x: { field: "name" },
        y: { field: "value" },
        fill: { field: "group" },
      },
      edits: [edit.select({ multi: true })],
    }),
    legendColor({
      anchor: "right",
      edit: edit.legend.category(),
    }),
  ],
}));
Try: Click a bar, Shift-click another, then click a legend swatch.

Continuous ramp sliders

For continuous numerical fields, edit: edit.legend.value() adds a draggable handle directly onto the colour gradient ramp. Dragging the handle writes the corresponding value back into the datum.

Drag the gradient ramp

Dragging the ramp handle updates the numeric temperature value.

mount(Elicit({
  width: 320, height: 210,
  margins: { top: 20, right: 16, bottom: 20, left: 20 },
  data: [ { temp: 18 } ],
  schema: { temp: { type: "quantitative", domain: [0, 30] } },
  axes: false,
  marks: [
    point({
      size: 35,
      channels: {
        x: { value: 80 },
        y: { value: 95 },
        fill: { field: "temp" },
      },
    }),
    legendColor({
      anchor: "right",
      edit: edit.legend.value(),
    }),
  ],
}));
Try: Drag the handle up and down along the gradient ramp.

Authoring categories on the scale

While swatch pickers write to a dataset row, edit.scale.categories() writes to the scale domain itself.

It adds three direct affordances to the legend: double-click a swatch to rename its category, click the × to delete it, and double-click the ＋ to append a new category. Renaming updates matching rows, and deleting removes them.

Rename, remove, and add categories

Double-click ＋ to append · double-click a label to rename · click × to remove.

mount(Elicit({
  width: 380, height: 220,
  margins: { top: 20, right: 16, bottom: 28, left: 40 },
  data: [
    { cat: "Alpha", val: 30 },
    { cat: "Beta", val: 55 },
    { cat: "Gamma", val: 40 },
  ],
  schema: {
    cat: { type: "categorical", domain: ["Alpha", "Beta", "Gamma"] },
    val: { type: "quantitative", domain: [0, 60] },
  },
  marks: [
    barY({
      channels: {
        x: { field: "cat" },
        y: { field: "val" },
        fill: { field: "cat" },
      },
    }),
    legendColor({
      anchor: "right",
      edit: edit.scale.categories(),
    }),
  ],
}));
Try: Double-click the ＋ icon to add a category · double-click a label to rename it.

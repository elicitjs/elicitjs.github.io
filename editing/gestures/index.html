Transforms & Modalities

A transform maps input into a channel's value through that channel's own scale. move translates position, resize adjusts radial magnitude, slide adjusts magnitude along an axis, rotate turns angles, cycle advances discrete categories, toggle picks a slot on and off, set writes a value outright, and rank reorders rows. custom takes anything else. A mark that accepts pointer drags also accepts keyboard arrow keys, through the same edit and the same constraints.

API reference

move(options)

Position edit — inverts the pointer on each positional channel. On x+y a 2D move; on y alone a bar drag.

move({ channel, channels, mode, pick, threshold, when, guide, constrain }) → Edit
Options
OptionTypeDefaultDescription
channelstringinjectedA single channel to govern (co-located edits inject their own).
channelsstring[]—Multiple channels for a joint move (e.g. ["x","y"]).
mode'absolute'|'relative''absolute'absolute puts the mark’s centre at the pointer. relative moves it by the drag distance instead, so the point you grabbed stays under the pointer — use it on anything with area, such as a rect or a sticker, where an absolute move snaps the mark as soon as you press it. Relative mode is direct-pick.
pick'direct'|'nearest'|'sweep''direct'Target selection; nearest grabs from anywhere within threshold.
guideboolean—Draw the constraint bounds + snap ring while dragging.
when, threshold, constrain——Shared Edit fields (see the Editing overview).
Returns / emits

An Edit. apply returns the datum with each governed field rewritten from the pointer.

resize(options)

Magnitude edit — the gesture radius from the mark centre inverts back to the channel value.

resize({ channel }) → Edit
Options
OptionTypeDefaultDescription
channelstringinjectedThe magnitude channel, usually size. Its scale must be invertible.
Returns / emits

An Edit returning the datum with the channel field set from the pointer radius.

slide(options)

Magnitude edit — a linear drag along one axis maps onto the channel's domain. The linear alternative to resize (radial).

slide({ axis, increase, extent, mode, channel }) → Edit
Options
OptionTypeDefaultDescription
axis'x' | 'y''x'Which pointer coordinate drives the value.
increase'left'|'right'|'up'|'down''left' / 'up'The direction that raises the value (left/right for axis x, up/down for axis y).
extentnumberglyph radius, else 120Drag distance that sweeps the full domain. Inside a composite's local box it defaults to the glyph's radius, so the gesture scales with the glyph.
mode'absolute' | 'relative''relative'relative — the value moves by the drag delta from the grab, so there is no jump. absolute — the value is read off the pointer's position on a fixed track centred on the mark; stateless, but it teleports unless the handle already sits at its value's place on that track. Both are direct-pick and coexist with a mark's other direct edits.
Returns / emits

An Edit returning the datum with the channel field set from the pointer's position along the axis.

rotate(options)

Angle edit — the pointer's angle about a pivot inverts back to the channel value (the scale's range is in degrees).

rotate({ pivot, fold, pick, relativeTo, channel }) → Edit
Options
OptionTypeDefaultDescription
pivot'plot' | 'mark''plot'The centre the angle is measured about — the plot, or the hit mark.
foldbooleantruetrue folds into a direction-agnostic cone; false uses full-circle degrees (a gauge/dial).
pick'plane' | 'direct''plane'plane turns the whole dataset; direct turns the touched datum alone (a needle handle).
relativeTostring—Measure the absolute angular distance from another angular channel (the “open the cone” gesture).
Returns / emits

An Edit with the channel field set from the pointer angle through the channel's scale.

cycle(options)

Discrete edit — a click advances the channel to the next value in its domain. Needs a stable ordinal domain.

cycle({ channel }) → Edit
Options
OptionTypeDefaultDescription
channelstringinjectedThe ordinal channel to advance, usually fill.
Returns / emits

An Edit (gesture click) returning the datum with the field stepped to the next domain entry.

toggle(options)

Slot edit — create and remove folded into the one gesture a checkbox has. Click an empty slot to mint a datum there; click an occupied one to take it back.

toggle({ channels, pick, when, stage }) → Edit
Options
OptionTypeDefaultDescription
channelsstring[]injectedThe channels whose inverted values name a slot. One (["x"]) toggles an option on a scale; two (["x","y"]) toggle a cell of a grid.
pick'plane' | 'probe''plane'probe previews the toggle on hover before the click commits it.
Returns / emits

An Edit returning the full dataset. Pairs with unique for one pick per row and count for a cap.

set(options)

Value edit — write a value straight into the channel’s field, whatever its type. Its input is the value itself, not a pixel, so it is the edit an external control drives.

set({ channel, channels, name, when, stage }) → Edit
Options
OptionTypeDefaultDescription
channel / channelsstring / string[]injectedWhich channel's field to write.
namestring—Address it from outside with el.control(name).set(value). accepts() reports what the channel’s scale allows.
Returns / emits

An Edit (gesture commit) returning the datum with that field set.

rank(options)

Reorder by dragging along a rank axis. The pointer inverts to a rank slot, and the datum swaps with whoever holds it, so ranks stay unique.

rank({ channel, channels, when, stage }) → Edit
Options
OptionTypeDefaultDescription
channel / channelsstring / string[]injectedThe rank axis — a band, point or quantitative scale. Place it on that channel: y: { field: "rank", edit: rank() }.
Returns / emits

An Edit returning the full dataset, with the two swapped rows rewritten.

custom(fn, options)

An arbitrary edit. fn becomes the edit’s apply; the descriptor still declares which gesture fires it.

custom((ctx) => datum | data[] | undefined, options?) → Edit
Options
OptionTypeDefaultDescription
fn(ctx) => …—datum is ctx.datum, event is the raw DOM event (ctx.event), ctx is the full EditContext (see Editing overview). Return a new datum, a full dataset, or undefined to no-op — whatever fields you put on the datum become data.
options.gesture'drag'|'click'|…'drag'Which gesture runs this edit. The engine matches event.type to this; fn itself does not choose the gesture.
options.pick, when, …——Any shared Edit fields (see the Editing overview).
Returns / emits

An Edit. Default gesture: "drag", pick: "direct". Full ctx field list lives on the Editing overview under EditContext.

Position — move

move() inverts the pointer coordinates on each positional channel it governs. On x and y together it performs a 2D translation; on y alone it is a 1D bar drag.

By default, the mark's centre snaps to the pointer. On marks with area (such as rect or sticker), pass mode: "relative" so the mark moves by the drag distance without jumping.

Move a point

edits: [move({ channels: ["x", "y"] })] — the pointer inverts onto both positional channels.

mount(Elicit({
  width: 380, height: 260,
  margins: { top: 14, right: 14, bottom: 26, left: 30 },
  data: [{ x: 20, y: 30 }, { x: 50, y: 62 }, { x: 78, y: 40 }],
  schema: {
    x: { type: "quantitative", domain: [0, 100] },
    y: { type: "quantitative", domain: [0, 100] },
  },
  marks: [
    point({
      fill: "#2563eb", stroke: "#1f2733", strokeWidth: 1, opacity: 0.85,
      size: 9,
      channels: {
        x: { field: "x" },
        y: { field: "y" },
      },
      // move() inverts the pointer on both positional channels — a 2D translate.
      edits: [ move({ channels: ["x", "y"] }) ],
    }),
  ],
}))
Try: Drag a dot anywhere.

Keyboard modality — arrow key nudging

Every mark that accepts a drag also accepts keyboard input through the same edit and constraints. Press Tab to focus a mark, then use arrow keys to nudge values by 1% of the scale domain (or Shift+arrow for 10%).

The keyboard shares the same domain clamping and validation as mouse drags. Enable focusOutline: true to display the browser's native focus ring.

Arrow keys move a point

A mark configured with move() accepts arrow keys automatically. Domain clamps hold for both modalities.

mount(Elicit({
  width: 420, height: 260,
  margins: { top: 16, right: 16, bottom: 32, left: 40 },
  focusOutline: true,
  schema: {
    effort: { type: "quantitative", domain: [0, 100] },
    value:  { type: "quantitative", domain: [0, 100] },
  },
  data: [
    { effort: 25, value: 70 },
    { effort: 60, value: 45 },
  ],
  constraints: [
    clamp({ min: 0, max: 100, field: "effort" }),
    clamp({ min: 0, max: 100, field: "value" }),
  ],
  marks: [
    point({
      size: 8, fill: "#2563eb",
      channels: {
        x: { field: "effort", edit: move() },
        y: { field: "value",  edit: move() },
      },
    }),
  ],
}));
Try: Tab until a dot is focused, then use the arrow keys (or Shift+arrow) to nudge its position.

Magnitude — resize (radial)

resize() inverts the drag radius from the mark's centre back into the channel's value (size: { edit: resize() }). Stroke widths remain constant while resizing.

Drag outward to grow

resize() maps the gesture radius back to the size field.

mount(Elicit({
  width: 380, height: 260,
  margins: { top: 14, right: 14, bottom: 26, left: 30 },
  data: [
    { x: 25, y: 50, mag: 3 }, { x: 55, y: 50, mag: 7 }, { x: 82, y: 50, mag: 11 },
  ],
  schema: {
    x:   { type: "quantitative", domain: [0, 100] },
    y:   { type: "quantitative", domain: [0, 100] },
    mag: { type: "quantitative", domain: [0, 14] },
  },
  constraints: [ clamp({ field: "mag", min: 1, max: 14 }) ],
  marks: [
    point({
      fill: "#ede9fe", stroke: "#7c3aed", strokeWidth: 2,
      channels: {
        x: { field: "x" },
        y: { field: "y" },
        size: { field: "mag", edit: resize() },
      },
    }),
  ],
}))
Try: Drag a dot outward or inward to change its size.

Magnitude — slide (linear)

slide() is the linear counterpart to resize. It reads how far the pointer moves along one axis and maps that onto the value's domain. Set axis to 'x' or 'y', and increase to 'left', 'right', 'up', or 'down'.

The default mode: "relative" alters the value by the drag delta from where you pressed. extent sets the drag distance required to sweep the full domain.

Slide along an axis

size: { edit: slide({ axis: "x", increase: "left" }) } — dragging left increases the value.

mount(Elicit({
  width: 380, height: 260,
  margins: { top: 14, right: 14, bottom: 26, left: 30 },
  data: [
    { x: 50, y: 50, mag: 7 },
  ],
  schema: {
    x:   { type: "quantitative", domain: [0, 100] },
    y:   { type: "quantitative", domain: [0, 100] },
    mag: { type: "quantitative", domain: [0, 14] },
  },
  constraints: [ clamp({ field: "mag", min: 1, max: 14 }) ],
  marks: [
    point({
      fill: "#ecfeff", stroke: "#0891b2", strokeWidth: 2,
      channels: {
        x: { field: "x" },
        y: { field: "y" },
        size: { field: "mag", edit: slide({ axis: "x", increase: "left" }) },
      },
    }),
  ],
}))
Try: Drag the dot left to grow it, right to shrink it.

Angle — rotate

rotate() inverts the pointer's angle about a pivot into angular degrees. Set pivot: "mark" to rotate around the mark's centre, or pivot: "plot" for the chart centre. Set fold: false for a full 360° dial, or fold: true for a directional cone.

Rotate a box

Pointer angle inverts onto theta relative to the mark centre.

mount(Elicit({
  width: 380, height: 260,
  margins: { top: 20, right: 20, bottom: 20, left: 20 },
  schema: {
    x:     { type: "quantitative", domain: [0, 100] },
    y:     { type: "quantitative", domain: [0, 100] },
    theta: { type: "quantitative", domain: [0, 360] },
  },
  data: [ { x: 50, y: 50, theta: 20 } ],
  marks: [
    rect({
      channels: {
        x: { field: "x" },
        y: { field: "y" },
        width:  { value: 110 },
        height: { value: 70 },
        fill:   { value: "#6366f1" },
        stroke: { value: "#3730a3" },
        // rotate() inverts the pointer's angle about the mark centre onto theta.
        angle: {
          field: "theta",
          scale: { range: [0, 360] },
          edit: rotate({ pick: "direct", pivot: "mark", fold: false }),
        },
      },
    }),
  ],
}))
Try: Drag the box to spin it around its centre.

Discrete — cycle, and combining gestures

cycle() advances an ordinal channel to the next value in its domain on a click. When multiple edits share a mark, when arbitrates which edit fires based on modifier keys.

Move · Shift-resize · click-cycle

when.noShift and when.shift split the drag; cycle() advances the fill category.

mount(Elicit({
  width: 380, height: 260,
  margins: { top: 14, right: 14, bottom: 26, left: 30 },
  data: [
    { x: 24, y: 70, mag: 5, team: "A" },
    { x: 55, y: 34, mag: 9, team: "B" },
    { x: 80, y: 60, mag: 12, team: "C" },
  ],
  schema: {
    x:    { type: "quantitative", domain: [0, 100] },
    y:    { type: "quantitative", domain: [0, 100] },
    mag:  { type: "quantitative", domain: [0, 14] },
    team: { type: "categorical",  domain: ["A", "B", "C"] },
  },
  constraints: [ clamp({ field: "mag", min: 1, max: 14 }) ],
  marks: [
    point({
      channels: {
        x: { field: "x" },
        y: { field: "y" },
        size: { field: "mag" },
        fill: { field: "team", edit: cycle() },
      },
      edits: [
        move({ channels: ["x", "y"], when: when.noShift }),  // plain drag = move
        resize({ channel: "size", when: when.shift }),        // shift-drag = resize
      ],
    }),
  ],
}))
Try: Drag to move · Shift+drag to resize · Click to recolour.

Custom transforms

custom(fn) sets fn as the edit's apply function. It receives an EditContext (ctx.datum, ctx.event, ctx.pointer, ctx.scales) and returns the updated datum or dataset.

Invert y directly

ctx.pointer contains plot pixels; scales.y.invertValue maps them back to data.

mount(Elicit({
  width: 380, height: 260,
  margins: { top: 14, right: 14, bottom: 26, left: 30 },
  data: [{ x: 30, y: 30 }, { x: 70, y: 70 }],
  schema: {
    x: { type: "quantitative", domain: [0, 100] },
    y: { type: "quantitative", domain: [0, 100] },
  },
  marks: [
    point({
      fill: "#2563eb",
      size: 8,
      channels: {
        x: { field: "x" },
        y: { field: "y" },
      },
      edits: [
        // default gesture: "drag" — pass { gesture: "click" } to change it
        custom((ctx) => ({
          ...ctx.datum,
          y: ctx.scales.y.invertValue(ctx.pointer.y),
          touched: true, // becomes data; omit if you only want to rewrite y
        })),
      ],
    }),
  ],
}))
Try: Drag a dot — y follows the pointer and the data panel reflects the updated field.

Responsive sizing

By default a chart draws at the exact width / height you give it, in pixels. The responsive option makes it fit its parent instead. "scale" wraps the SVG in a viewBox, so the browser stretches one drawing to the container and the aspect ratio holds. "reflow" measures the parent and redraws at native pixels on resize, so text stays crisp, the width tracks the container, and the height stays the value you set. Either way, the width / height you pass is the design size.

API reference

Elicit({ responsive, width, height, … })

One option on the ElicitSpec. Everything else about a chart is unchanged — marks, edits and scales all read the (possibly resized) inner dimensions, so the whole scene reflows for free.

Options
OptionTypeDefaultDescription
responsive'fixed' | 'scale' | 'reflow' | true'fixed''fixed': draw at the pixel width/height. 'scale': viewBox, SVG fills the parent width (aspect kept). 'reflow' (or true): re-draw at the parent's measured width on resize.
width / heightnumber600 / 400The design size — the exact pixels in "fixed", the viewBox in "scale", and the initial width + fixed height in "reflow".
Returns / emits

The same ElicitElement. A "reflow" chart also wires a ResizeObserver; call el.destroy() when you unmount it to detach the observer (a no-op in the other modes).

Scale (viewBox)

responsive: "scale" keeps the chart's 480×300 aspect ratio and stretches it to fill the column; text and strokes scale with it. Reach for it when a chart should grow and shrink with its container and some drift in aspect is fine.

Fills the parent width

the same spec at responsive: "scale"; the SVG scales to this card via a viewBox.

const cats = ["A","B","C","D","E"];
mount(Elicit({
  width: 480, height: 300,
  responsive: "scale",
  margins: { top: 16, right: 12, bottom: 28, left: 34 },
  data: cats.map((c, i) => ({ cat: c, value: [30, 80, 45, 60, 20][i] })),
  schema: {
    cat:   { type: "categorical", domain: cats },
    value: { type: "quantitative", domain: [0, 100] },
  },
  scales: { x: { type: "band" } },
  marks: [
    barY({ fill: "#4f46e5", channels: {
      x: { field: "cat" },
      y: { field: "value", edit: move() },
    } }),
  ],
}));

Reflow (ResizeObserver)

responsive: "reflow" measures this card and redraws at native pixels: the width tracks the container while the height stays 300. Resize the window and the bars re-lay out crisply, with no scaling blur. Call el.destroy() on unmount.

Redraws to the parent width

responsive: "reflow"; drag a bar, then resize the window — layout recomputes.

Fixed (default)

With no responsive option (or responsive: "fixed") the chart is exactly 320×240 pixels, whatever the container. Use it when a chart must be a precise size.

Exact pixels

the default: a 320×240 chart that ignores the parent width.

const cats = ["A","B","C","D","E"];

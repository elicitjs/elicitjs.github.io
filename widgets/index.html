Widgets

Opinionated survey instruments — option rings, cell grids, tracks — each a pure recipe over the core API. They add no interaction surface: the look lives entirely in the guide layer, and the behaviour is a normal mark + a normal edit on the probe driver + a normal constraint. The Likert scale below is shown both as the one-line widget and as its plain-API twin, so you can see exactly what a widget expands to — every other instrument here is just the widget. Each factory returns an ElicitSpec: render with Elicit(widgets.likert({…})).

API reference

widgets.likert · multipleChoice · slider · matrix · lineCone · ranking · allocation · …

Import from elicit.widgets. Each returns an ElicitSpec; pass it straight to Elicit. The chart elicits one dataset, so getData() reads the answer.

Returns / emits

An ElicitSpec — an ordinary spec, so you can read it, change one key, and pass it on. The chrome each widget draws itself with is a guide: guides.prompt, guides.optionRings, guides.cellGrid, guides.sliderTrack, guides.crosshair. The plain-API twins below use those same guides, so each block stands alone.

Likert scale — widget & plain API

A point on a band of options + create (probe) + count(\{ max: 1, replace \}). Hover to preview the answer, click to fill it. The plain-API twin draws the same look with inline guides.custom helpers and the same mark + edit + constraint — the widget is only a shorthand for it.

As a widget

Rings, track and labels come from the guide layer.

mount(Elicit(widgets.likert({
  question: "This tool is easy to use",
  options: ["Strongly disagree","Disagree","Neutral","Agree","Strongly agree"],
})));
Try: hover across the scale, then click.

The same thing, plain API

Same mark, edit, and constraint — rings/prompt defined inline as guides. This is what widgets.likert expands to.

const options = ["Strongly disagree","Disagree","Neutral","Agree","Strongly agree"];
const radius = 11;

const prompt = (text) => guides.custom(() => [{
  type: "text", x: 0, y: -18, text,
  textAnchor: "start", fontSize: 13, fill: "#0f172a",
}]);

const optionRings = () => guides.custom((ctx) => {
  const cats = ctx.scales.x.domainConfig || [];
  const cy = ctx.height / 2;
  const cxOf = (c) => ctx.scales.x.encode(c);
  const nodes = [];
  for (let i = 0; i < cats.length - 1; i++) {
    nodes.push({
      type: "line",
      x1: cxOf(cats[i]) + radius, y1: cy,
      x2: cxOf(cats[i + 1]) - radius, y2: cy,
      stroke: "#e2e8f0", strokeWidth: 3, background: true,
    });
  }
  for (const c of cats) {
    nodes.push({
      type: "circle", cx: cxOf(c), cy, r: radius,
      fill: "none", stroke: "#cbd5e1", strokeWidth: 1.5,
    });
    nodes.push({
      type: "text", x: cxOf(c), y: cy + 30, text: String(c),
      textAnchor: "middle", fontSize: 12, fill: "#334155",
    });
  }
  return nodes;
});

mount(Elicit({
  width: 560, height: 130,
  margins: { top: 34, right: 60, bottom: 44, left: 60 },
  axes: false,
  data: [],
  schema: { choice: { type: "ordinal", domain: options } },
  scales: { x: { type: "band" } },
  constraints: [ count({ max: 1, strategy: "replace" }) ],
  guides: [ prompt("This tool is easy to use"), optionRings() ],
  marks: [
    point({
      id: "likert",
      size: radius - 3,
      fill: "#2563eb",
      channels: { x: { field: "choice" } },
      edits: [ create({ pick: "probe", channels: ["x"], advance: false }) ],
    }),
  ],
}));
Try: same look, same interaction — change any line to customize.

Multiple choice

toggle() folds create and remove into one gesture: click an empty option to pick it, click your pick to take it back. count() caps the total.

Multiple choice (pick ≤ 2)

The hover shows whether a click will pick or un-pick.

mount(Elicit(widgets.multipleChoice({
  question: "Which apply?",
  options: ["Fast","Cheap","Reliable","Simple"],
  max: 2,
})));
Try: pick two, then click one again.

Slider

A single knob that tracks the pointer and settles on click or drag-release — move(\{ pick: "probe" \}). snap() lands it on steps.

Slider

Track, end caps and value labels are guides.

mount(Elicit(widgets.slider({
  question: "How likely is it? (%)",
  domain: [0, 100], step: 5, value: 40,
})));
Try: move across the track and click — or grab the knob and drag.

Question matrix

Band y of questions × band x of options. toggle() on the (x, y) tuple names a cell; unique(\{ field: "question", replace \}) keeps one answer per row.

Question matrix

The cell grid is a guide, so it never swallows the click.

mount(Elicit(widgets.matrix({
  question: "Rate each aspect",
  questions: ["Speed","Cost","Support"],
  options: ["Poor","OK","Good","Great"],
})));
Try: answer each row; click a row again elsewhere to change it.

Line + Cone

The two-step correlation instrument: aim the line and click, open the cone and click. getData() returns [\{ r, spread \}], and on("stage") says which question the reader is on (2 = both answered).

It is a preset, not a mark: trendBand + trend over one dataset, with the correlation stated as a pinned intercept: \{ datum: 0 \} channel and two clamp constraints. Nothing about it is special-cased — the same spec written out sits on the trend page. The chart is sized to a square inner plot, which is what makes the line’s screen angle read as r.

Line + Cone

Crosshair frame and high/low variable labels are guides.

const chart = Elicit(widgets.lineCone({
  question: "What is the relationship?",
  x: "Exercise amount", y: "Body weight",
}));
mount(chart);
const out = document.createElement("div");
out.style.cssText = "font:12px ui-monospace,monospace;color:#64748b";
const show = () => {
  const d = chart.getData()[0];
  out.textContent = "stage " + chart.getStage() +
    "  ·  r=" + d.r.toFixed(2) + "  spread=" + d.spread.toFixed(2);
};
chart.on("change", show); chart.on("stage", show); show();
mount(out);
Try: move, click, move, click.

Customizing styles

For a whole styled family, pass a theme — every widget accepts one, and it restyles the answer ink, chrome, and affordances together (see Theming). For one-off tweaks, the look is just guides + mark paint, so you can repaint the answer mark or swap the affordance in the plain-API twin above — behaviour (edits / constraints) stays put.

Restyle with a theme

widgets.slider({ …, theme: themes.survey }) — one object restyles the instrument.

// The same slider, restyled by themes.survey — answer ink, track, and labels
// all follow the theme. See /theming.
mount(Elicit(widgets.slider({
  question: "How confident are you?",
  domain: [0, 100],
  value: 60,
  theme: themes.survey,
})));
Try: drag the knob — only the look changed.

More instruments

Ranking, allocation, tokens, intervals, histograms, regions, thermometers, and labeled values — each a recipe over marks + edits + constraints, and each accepting the same question / value / onChange / stage / theme options.

Ranking

Drag items to reorder. It expands to a rank edit.

mount(Elicit(widgets.ranking({
  question: "Rank these priorities",
  items: ["Cost", "Speed", "Quality", "Risk"],
})));
Try: Drag a dot up or down to swap ranks.

Allocation

Bars that redistribute to keep a fixed sum.

mount(Elicit(widgets.allocation({
  question: "Allocate 100 points",
  categories: ["A", "B", "C", "D"],
  total: 100,
})));
Try: Drag a bar — siblings rebalance to 100.

Region

rect + brushRect for a 2-D belief box.

mount(Elicit(widgets.region({
  question: "Where do you expect the outcome?",
})));
Try: Drag edges, corners, or the body.

Interval / CI

Drag the mean to translate the whole interval; drag a cap to resize one end.

mount(Elicit(widgets.interval({
  question: "Your estimate and range",
  mean: 50, lo: 30, hi: 70,
})));
Try: Drag the centre — lo/hi follow. Drag a cap — mean stays put.

Thermometer

A single value as a vertical bar — probe drag, snap to step.

mount(Elicit(widgets.thermometer({
  question: "How likely is rain tomorrow?",
  domain: [0, 100],
  step: 5,
  value: 40,
})));
Try: Drag the bar (or move & click) — it snaps to the step.

Histogram

Editable frequency bins — drag each bar to its count.

mount(Elicit(widgets.histogram({
  question: "How many cups of coffee per day?",
  bins: ["0", "1", "2", "3", "4+"],
  max: 40,
})));
Try: Drag a bar up or down to set its count.

Probability tokens

Discrete mass as stacked tokens — probe-create a ghost token, click to drop; alt-click removes.

mount(Elicit(widgets.probabilityTokens({
  question: "Spread 20 tokens over the outcomes you expect",
  bins: ["Low", "Med", "High"],
  maxTokens: 20,
})));
Try: Hover a bin and click to drop a token · Alt-click to remove.

Labeled value

A draggable numeric readout — the number is the mark.

mount(Elicit(widgets.labeledValue({
  question: "Your point estimate",
  value: 42,
  domain: [0, 100],
})));
Try: Drag the number up or down.

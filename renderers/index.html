Renderers — the drawing backend is swappable

A mark produces plain-data scene nodes — a circle at cx,cy, a rect, a path. The engine collects them and hands the whole scene to a renderer, which turns nodes into pixels and reports gestures back. This seam is the only coupling between the engine and the screen: marks, edits, scales, guides, and constraints all behave the same under any renderer. Swap the renderer through renderer: on the spec and nothing upstream changes.

The default is new D3Renderer(), an SVG backend. new CanvasRenderer() implements the same contract (render(context) in, onEvent out) and draws to a <canvas>. The examples below run entirely on canvas — every edit behaves exactly as it does under SVG, because the interaction model lives in the engine.

Direct-pick drag, on canvas

Under SVG, the browser hit-tests: it picks the element under the pointer. A canvas is a single element, so the canvas renderer finds the touched mark geometrically, using the same distance math as the nearest pick, then dispatches the same move edit. Drag a bar and the gesture inverts through the y scale and rewrites the value, as it does under SVG.

Drag a value (canvas)

renderer: new CanvasRenderer(). y carries edit: move(); the direct-pick target is hit-tested geometrically against the scene nodes.

mount(Elicit({
  width: 380, height: 260,
  renderer: new CanvasRenderer(),
  margins: { top: 14, right: 14, bottom: 26, left: 30 },
  data: [
    { x: "A", y: 20 }, { x: "B", y: 45 },
    { x: "C", y: 30 }, { x: "D", y: 60 },
  ],
  schema: {
    x: { type: "categorical", domain: ["A", "B", "C", "D"] },
    y: { type: "quantitative", domain: [0, 100] },
  },
  marks: [
    bar({
      fill: "#4f46e5",
      channels: {
        x: { field: "x" },
        y: { field: "y", edit: move() },
      },
    }),
  ],
}))
Try: Drag a bar up or down.

Plane gestures, on canvas

Plane-driven edits (sweep, draw, nearest, create) resolve their target straight from the pointer coordinates. The canvas renderer feeds those coordinates through the same pointer state machine, so a you-draw-it sweep works unchanged.

Sweep a line (canvas)

A plane-pick sweep: drag across the plot to redraw the line. It works from pointer coordinates through the scale, with no node identity needed.

mount(Elicit({
  width: 420, height: 260,
  renderer: new CanvasRenderer(),
  margins: { top: 16, right: 16, bottom: 40, left: 44 },
  data: [
    { month: 0, demand: 50 }, { month: 1, demand: 50 },
    { month: 2, demand: 50 }, { month: 3, demand: 50 },
    { month: 4, demand: 50 }, { month: 5, demand: 50 },
  ],
  schema: {
    month:  { type: "quantitative", domain: [0, 5] },
    demand: { type: "quantitative", domain: [0, 100] },
  },
  axes: { x: { title: "Month" }, y: { title: "Demand" } },
  marks: [
    lineY({
      stroke: "#059669", strokeWidth: 3, curve: "catmullRom",
      channels: {
        x: { field: "month" },
        y: { field: "demand", edit: move({ pick: "sweep", guide: true }) },
      },
    }),
  ],
}))
Try: Drag left-to-right across the chart to reshape the line.

Rect

The generalized bar: each axis independently resolves its extent as a span (x1/x2, y1/y2), a fixed pixel size (width/height) centred on an anchor, a categorical band, or a baseline→value length — so a rectangle can span both axes at once, as in Observable Plot's rect (heatmap cells, 2-D regions, binned histograms, annotation boxes). rect spans both axes; rectX / rectY force one axis to a baseline→value length. Prefer bar when one axis is a category band and the other a value (classic elicitation bars); use rect when both axes are spans/bands, and pair it with brushRect() for edge/corner/body editing.

API reference

rect(options) · rectX(options) · rectY(options)

Import from elicit.plot. rect spans both axes; rectX forces value on x (y a span/band), rectY forces value on y. All three share these options.

rect({ channels, orientation, width, height, rx, edits, id }) → Feature
rectX(options) → Feature   // value on x
rectY(options) → Feature   // value on y

A feature emitting one rect per datum.

A 2-D rectangle (both axes are spans)

Give both axes explicit endpoints and each datum draws a rectangle spanning x1→x2 and y1→y2.

Region boxes

x1/x2 and y1/y2 place each rect; fill by a field.

mount(Elicit({
  width: 360, height: 260,
  margins: { top: 16, right: 16, bottom: 28, left: 34 },
  data: [
    { x1: 1, x2: 4, y1: 1, y2: 3, kind: "a" },
    { x1: 5, x2: 8, y1: 4, y2: 7, kind: "b" },
    { x1: 3, x2: 6, y1: 6, y2: 9, kind: "a" },
  ],
  schema: {
    x1: { type: "quantitative", domain: [0, 10] },
    x2: { type: "quantitative", domain: [0, 10] },
    y1: { type: "quantitative", domain: [0, 10] },
    y2: { type: "quantitative", domain: [0, 10] },
    kind: { type: "categorical", domain: ["a", "b"] },
  },
  marks: [
    rect({
      fillOpacity: 0.6,
      channels: {
        x1: { field: "x1" }, x2: { field: "x2" },
        y1: { field: "y1" }, y2: { field: "y2" },
        fill: { field: "kind" },
      },
    }),
  ],
}))

Heatmap (both axes categorical)

Put a category on both axes and each datum draws one cell at that (x, y) intersection — a heatmap. A quantitative fill resolves to a sequential colour ramp; a categorical fill to a palette. Band scales pad by default, so set scale: { padding: 0 } on each axis to close the gap and let the cells touch. Colour isn't gesture-invertible, so edit a cell's value through the ramp: select() on the cells makes the one you click the target row, and legendColor({ edit: edit.legend.value() }) drags that row's value along the ramp.

Coloured cells

A category on x and y; fill by a quantitative field; padding 0 so cells touch.

mount(Elicit({
  width: 420, height: 260,
  margins: { top: 16, right: 84, bottom: 30, left: 56 },
  data: [
    { day: "Mon", slot: "AM", load: 4 },  { day: "Mon", slot: "PM", load: 9 },  { day: "Mon", slot: "Eve", load: 6 },
    { day: "Tue", slot: "AM", load: 7 },  { day: "Tue", slot: "PM", load: 14 }, { day: "Tue", slot: "Eve", load: 8 },
    { day: "Wed", slot: "AM", load: 12 }, { day: "Wed", slot: "PM", load: 20 }, { day: "Wed", slot: "Eve", load: 11 },
    { day: "Thu", slot: "AM", load: 6 },  { day: "Thu", slot: "PM", load: 16 }, { day: "Thu", slot: "Eve", load: 10 },
  ],
  schema: {
    day:  { type: "categorical", domain: ["Mon", "Tue", "Wed", "Thu"] },
    slot: { type: "categorical", domain: ["AM", "PM", "Eve"] },
    load: { type: "quantitative", domain: [0, 20] },
  },
  marks: [
    // A category on BOTH axes draws one cell per (day, slot). `scale: { padding: 0 }`
    // removes the band gap so the cells touch, as a heatmap wants. A quantitative
    // `fill` resolves to a sequential colour ramp.
    // `select()` makes a cell the target row, so the legend edits the one you click.
    rect({
      stroke: "#fff", strokeWidth: 1,
      edits: [ edit.select() ],
      channels: {
        x:    { field: "day",  scale: { padding: 0 } },
        y:    { field: "slot", scale: { padding: 0 } },
        fill: { field: "load" },
      },
    }),
    // Colour isn't gesture-invertible, so the ramp handle sets the value by hand.
    // It tracks the selected cell — click a cell, then drag the handle to set it.
    legendColor({ anchor: "right", title: "load", edit: edit.legend.value() }),
  ],
}))
Try: Click a cell to select it, then drag the legend handle to set its value.

Fixed-size boxes (width/height)

Give an axis an explicit pixel extent with width (x) or height (y) and the rect becomes a fixed-size box centred on its x/y anchor — the SVG-native parameterisation, alongside x1/x2 spans and band cells. An explicit size overrides the band interval and the baseline→value length. The anchor is a positional channel, so a move() on x and y moves the whole box.

Boxes at data points

x/y anchor each box; width/height set a constant 28×28 px size.

mount(Elicit({
  width: 420, height: 260,
  margins: { top: 16, right: 16, bottom: 30, left: 40 },
  data: [
    { x: 1, y: 8,  tag: "a" },
    { x: 3, y: 3,  tag: "b" },
    { x: 5, y: 6,  tag: "c" },
    { x: 7, y: 2,  tag: "d" },
  ],
  schema: {
    x:   { type: "quantitative", domain: [0, 8] },
    y:   { type: "quantitative", domain: [0, 10] },
    tag: { type: "categorical", domain: ["a", "b", "c", "d"] },
  },
  marks: [
    // `width` / `height` are pixel extents, so each rect is a fixed 28x28 box
    // centred on its (x, y) anchor — the SVG-native form, alongside x1/x2 spans
    // and band cells. The anchor stays a positional channel: a drag on x and y
    // inverts the pointer through both scales, so the whole box moves.
    rect({
      fill: "#2563eb", fillOpacity: 0.8,
      channels: {
        x:      { field: "x", edit: edit.move() },
        y:      { field: "y", edit: edit.move() },
        width:  { value: 28 },
        height: { value: 28 },
      },
    }),
  ],
}))
Try: Drag a box to move it (its size stays fixed).

Binned histogram (rectY)

A histogram is a vertical rect whose x is a quantitative bin span (x1/x2) and whose y is a count from the baseline — that is exactly rectY. Data must already be binned, one row per bin; there is no binning transform. Prefer barY when bins are categorical labels instead of numeric edges.

Pre-binned counts

x1/x2 place each bin on a shared quantitative x; y is the count.

mount(Elicit({
  width: 400, height: 260,
  margins: { top: 16, right: 16, bottom: 28, left: 34 },
  data: [
    { x1: 0, x2: 2, n: 4 },
    { x1: 2, x2: 4, n: 12 },
    { x1: 4, x2: 6, n: 18 },
    { x1: 6, x2: 8, n: 9 },
    { x1: 8, x2: 10, n: 3 },
  ],
  schema: {
    x1: { type: "quantitative", domain: [0, 10] },
    x2: { type: "quantitative", domain: [0, 10] },
    n:  { type: "quantitative", domain: [0, 24] },
  },
  marks: [
    rectY({
      fill: "#2563eb", fillOpacity: 0.75, stroke: "#1e40af",
      channels: {
        x1: { field: "x1" },
        x2: { field: "x2" },
        y:  { field: "n" },
      },
    }),
  ],
}))

Editable bin heights

Drag on y to reshape the belief distribution; clamp keeps counts ≥ 0.

mount(Elicit({
  width: 400, height: 260,
  margins: { top: 16, right: 16, bottom: 28, left: 34 },
  data: [
    { x1: 0, x2: 2, n: 4 },
    { x1: 2, x2: 4, n: 12 },
    { x1: 4, x2: 6, n: 18 },
    { x1: 6, x2: 8, n: 9 },
    { x1: 8, x2: 10, n: 3 },
  ],
  schema: {
    x1: { type: "quantitative", domain: [0, 10] },
    x2: { type: "quantitative", domain: [0, 10] },
    n:  { type: "quantitative", domain: [0, 24] },
  },
  constraints: [clamp({ min: 0, max: 24, field: "n" })],
  marks: [
    rectY({
      fill: "#0d9488", fillOpacity: 0.75, stroke: "#0f766e",
      channels: {
        x1: { field: "x1" },
        x2: { field: "x2" },
        y:  { field: "n", edit: move({ guide: true }) },
      },
    }),
  ],
}))
Try: Drag a bin’s top edge to change its count.

Composable 2-D editing (brushRect)

brushRect() edits all four extents, opt-in and composable: grab an edge to resize one side, a corner to resize two extents, the body to move the whole rect. resize ('both' | 'x' | 'y' | 'none') picks which axes resize; move (boolean) toggles body-drag — so you can ship resize-one-axis, move-only, or resize-only variants.

Full 2-D: edges, corners, body

Default brushRect(): every direction live.

mount(Elicit({
  width: 360, height: 260,
  margins: { top: 16, right: 16, bottom: 28, left: 34 },
  data: [ { x1: 2, x2: 6, y1: 2, y2: 6 } ],
  schema: {
    x1: { type: "quantitative", domain: [0, 10] },
    x2: { type: "quantitative", domain: [0, 10] },
    y1: { type: "quantitative", domain: [0, 10] },
    y2: { type: "quantitative", domain: [0, 10] },
  },
  marks: [
    rect({
      fill: "#2563eb", fillOpacity: 0.5, stroke: "#2563eb",
      channels: {
        x1: { field: "x1" }, x2: { field: "x2" },
        y1: { field: "y1" }, y2: { field: "y2" },
      },
      edits: [ brushRect({ edgeInset: 12 }) ],
    }),
  ],
}))
Try: Drag an edge to resize a side, a corner to resize two extents, or the body to move.

Creating rects

A rect is a data mark, so it's creatable like any other (see Create · Remove · Anchors) — with one wrinkle: a click gives a single point, but a rect needs a size, so a creator must seed the extent. A rectY-style rect (band or baseline→value length) gets its size from the axis and creates like a bar. A 2-D span rect (x1/x2, y1/y2) needs the opposite corner supplied through create({ defaults: { x2, y2 } }), then brushRect() shapes it. Skip the extent and the new row mints zero-size and invisible — the dev build warns you. Geo's edit.geo.createRect() is the purpose-built version: it mints a box sized from default spans around the click.

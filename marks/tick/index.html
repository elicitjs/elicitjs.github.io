Tick

A tick is bar’s zero-thickness sibling: a thin line marking a value on the linear axis and spanning the other axis. Over a category band it reads as a value marker (like a bar without the fill); over a full continuous extent it reads as a rug / strip. inset shrinks each end, length fixes a centred length.

API reference

tick(options) · tickY(options) · tickX(options)

Import from elicit.plot. tick infers the value axis from which axis is a band; tickY marks a value on y (spans the x band), tickX on x.

tick({ channels, orientation, inset, length, edits, id }) → Feature
tickY(options) → Feature   // value on y
tickX(options) → Feature   // value on x
Options
OptionTypeDefaultDescription
channelsobject{}One band axis (span) + one linear axis (the marked value). See Channels.
orientation'vertical' | 'horizontal'autoWhich axis the value runs along ('vertical' = y). Inferred from which axis is a band; tickY / tickX pin it.
insetnumber0Pixels to shrink each end of the span.
lengthnumber—Explicit centred span length in pixels. On a band axis it centres in the band; when the span axis also has a channel (e.g. scatter x+y), it centres on that channel’s encoded position so a short tick sits on the datum.
editsEdit[]—Mark-level edits; per-channel edits live in the channels map.
stroke, strokeWidth, …stylestroke:'steelblue'Style shorthands / channels.
Channels
ChannelTypeDescription
xband | linearCategory (band) or value (linear), per orientation.
yband | linearThe other axis; the value axis carries edit: move() to drag the tick.
stroke, strokeWidth, opacityconst | fieldStandard style surface.
Returns / emits

A feature emitting one line per datum (a bar with zero thickness).

A value marker across bands

tickY marks a y value spanning each category's band — the same channel/edit model as a bar, so it drags identically.

Ticks over a band axis

One tick per category, spanning the band at its y value.

mount(Elicit({
  width: 380, height: 240,
  margins: { top: 14, right: 14, bottom: 26, left: 30 },
  data: [
    { x: "A", y: 20 }, { x: "B", y: 45 },
    { x: "C", y: 30 }, { x: "D", y: 60 },
  ],
  schema: {
    x: { type: "categorical", domain: ["A", "B", "C", "D"] },
    y: { type: "quantitative", domain: [0, 100] },
  },
  marks: [
    tickY({
      stroke: "#4f46e5", strokeWidth: 3,
      channels: {
        x: { field: "x" },
        y: { field: "y" },
      },
    }),
  ],
}))

Drag a value (ticks)

Same y edit as a bar; pick: "nearest" grabs the tick from anywhere in its column.

mount(Elicit({
  width: 380, height: 260,
  margins: { top: 14, right: 14, bottom: 26, left: 30 },
  data: [
    { x: "A", y: 20 }, { x: "B", y: 45 },
    { x: "C", y: 30 }, { x: "D", y: 60 },
  ],
  schema: {
    x: { type: "categorical", domain: ["A", "B", "C", "D"] },
    y: { type: "quantitative", domain: [0, 100] },
  },
  marks: [
    tickY({
      stroke: "#4f46e5", strokeWidth: 3,
      channels: {
        x: { field: "x" },
        y: { field: "y",
             edit: move({ pick: "nearest" }) },
      },
    }),
  ],
}))
Try: Drag a tick up or down — from anywhere in its column.

A rug / strip plot

With no band on the other axis, a tick spans the full extent — a strip of marks at each datum's position. inset trims the ends so the strip floats off the frame.

tickX — a distribution strip

Values along x, each drawn as a vertical mark spanning y. inset shortens them.

mount(Elicit({
  width: 400, height: 200,
  margins: { top: 16, right: 16, bottom: 28, left: 16 },
  data: [
    { v: 12 }, { v: 18 }, { v: 21 }, { v: 34 }, { v: 39 },
    { v: 41 }, { v: 55 }, { v: 58 }, { v: 63 }, { v: 71 }, { v: 84 },
  ],
  schema: {
    v: { type: "quantitative", domain: [0, 100] },
  },
  marks: [
    tickX({
      stroke: "#0d9488", strokeWidth: 2, inset: 10,
      channels: {
        x: { field: "v" },
      },
    }),
  ],
}))

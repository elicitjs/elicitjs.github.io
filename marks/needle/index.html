Needle

A pivoted needle (NYT-style gauge or software dial). It encodes a value on the theta channel — the polar angular position, in degrees via the channel’s scale — and draws a tapered pointer + hub. The default semicircle is horizontal (left → right through the top, like a speedometer). Use orient (top·right·bottom·left), arc: "full", or explicit start/end — and keep scale.range in sync. Optional x/y place the pivot on categorical or linear axes (many small needles in one chart).

API reference

needle(options)

Import from elicit.plot. One needle (+ hub) per datum.

Semicircle gauge + center text

A composite of axisRadial (ticks), needle, and text. Default orient is top: 0 on the left, max on the right.

Quantitative gauge

Domain [0, 100] maps to [180°, 0°] (left → right). Drag the needle.

mount(Elicit({
  width: 320, height: 200,
  margins: { top: 24, right: 16, bottom: 16, left: 16 },
  axes: false,
  data: [{ n: 62 }],
  schema: { n: { type: "quantitative", domain: [0, 100] } },
  marks: [
    composite({
      id: "gauge",
      parts: [
        axisRadial({
          orient: "top", radius: 100, ticks: 5,
          channels: { theta: { field: "n", scale: { range: [180, 0] } } },
        }),
        needle({
          length: 90, fill: "#1d4ed8",
          channels: {
            theta: {
              field: "n",
              scale: { range: [180, 0] },
              edit: rotate({ pivot: "mark", fold: false, pick: "direct" }),
            },
          },
        }),
        text({
          fontSize: 22, dy: 28,
          format: ".0f",
          channels: {
            text: { field: "n" },
            textAnchor: { value: "middle" },
            lineAnchor: { value: "middle" },
          },
        }),
      ],
    }),
  ],
}));

Ableton-style knob

A software knob is a composite: a donut-slice ring (dark track + value fill) and a thin needle that shares the same theta scale. The ring is a tiny mark over authoring.arcPath — stock arc / donut partition a total among rows, while a knob's fill is one value swept from the arc's start. The needle carries rotate({ pivot: "mark", fold: false, pick: "direct" }); the ring stays inert and re-derives.

The span is Ableton's 270° arc with a gap at the bottom: start: 225 (~7 o'clock) to end: -45 (~5 o'clock). Keep scale.range in sync with that span.

Compress knob

Ring fill + needle over one quantitative field. Drag the needle — the cyan slice follows.

// Ableton-style knob: a donut-slice ring (track + value fill) plus a needle.
// The ring is a tiny mark over authoring.arcPath; the needle carries rotate().
// Stock arc/donut partition a total among rows — a knob's fill is one value
// swept from the arc's start, so the ring is a short authoring mark instead.
const START = 225; // ~7 o'clock
const END = -45;   // ~5 o'clock — 270° clockwise through the top

function knobArc(options = {}) {
  const opts = authoring.normalizeMarkOptions(options, {
    mark: "knobArc",
    allow: ["outerRadius", "innerRadius", "start", "end", "track"],
  });
  const {
    channels = {},
    outerRadius = 90,
    innerRadius = 78,
    start = START,
    end = END,
    track = "#1a1a1a",
  } = opts;
  return {
    ...authoring.markCommon(opts),
    type: "knobArc",
    channels,
    build(data, scales, width, height) {
      const cx = width / 2, cy = height / 2;
      return data.flatMap((d, i) => {
        const deg = authoring.encodeAngle(scales, channels, d, start, i, data);
        const style = authoring.resolveStyle(
          scales, channels, d, { fill: "#00aebc" }, i, data,
        );
        const nodes = [];
        const trackD = authoring.arcPath(cx, cy, outerRadius, start, end, { innerRadius });
        if (trackD) {
          nodes.push({
            type: "path", d: trackD, fill: track, stroke: "none",
            data: d, index: i, pointerEvents: "none",
          });
        }
        const fillD = authoring.arcPath(cx, cy, outerRadius, start, deg, { innerRadius });
        if (fillD) {
          nodes.push({
            type: "path", d: fillD, ...style, stroke: "none",
            data: d, index: i, pointerEvents: "none",
          });
        }
        // Max tick — the small end-cap Ableton puts at 5 o'clock.
        const tip = authoring.polarToXY(cx, cy, (outerRadius + innerRadius) / 2, end);
        nodes.push({
          type: "circle", cx: tip.x, cy: tip.y, r: 2.5,
          fill: track, stroke: "none",
          data: d, index: i, pointerEvents: "none",
        });
        return nodes;
      });
    },
  };
}

mount(Elicit({
  width: 260, height: 280,
  margins: { top: 40, right: 24, bottom: 44, left: 24 },
  axes: false,
  theme: { background: "#323232", ink: "#b4b4b4" },
  data: [{ level: 25 }],
  schema: { level: { type: "quantitative", domain: [0, 100] } },
  marks: [
    composite({
      id: "knob",
      parts: [
        text({
          fontSize: 13, dy: -108,
          channels: {
            text: { value: "Compress" },
            fill: { value: "#b4b4b4" },
            textAnchor: { value: "middle" },
            lineAnchor: { value: "middle" },
          },
        }),
        knobArc({
          outerRadius: 88, innerRadius: 76,
          start: START, end: END,
          track: "#1a1a1a",
          channels: {
            theta: { field: "level", scale: { range: [START, END] } },
            fill: { value: "#00aebc" },
          },
        }),
        needle({
          length: 70, baseWidth: 2.5,
          handles: "hit",
          fill: "#1a1a1a", stroke: "#1a1a1a",
          channels: {
            theta: {
              field: "level",
              scale: { range: [START, END] },
              edit: rotate({ pivot: "mark", fold: false, pick: "direct" }),
            },
          },
        }),
        text({
          fontSize: 14, dy: 108,
          format: (v) => `${Math.round(v)} %`,
          channels: {
            text: { field: "level" },
            fill: { value: "#b4b4b4" },
            textAnchor: { value: "middle" },
            lineAnchor: { value: "middle" },
          },
        }),
      ],
    }),
  ],
}))

Categorical needle

A discrete theta field uses a point scale — drag snaps to the nearest category. Coloured bands come from axisRadial({ bands: true }).

Likelihood gauge

Seven ordered categories across a top-facing arc.

mount(Elicit({
  width: 360, height: 220,
  margins: { top: 40, right: 70, bottom: 20, left: 70 },
  axes: false,
  // Let the long band labels ("VERY LIKELY D" …) spill into the margin instead of
  // being clipped by the plot edge.
  overflow: "visible",
  data: [{ chance: "LEANING D" }],
  schema: {
    chance: {
      type: "ordinal",
      domain: ["VERY LIKELY D", "LIKELY D", "LEANING D", "TOSSUP",
               "LEANING R", "LIKELY R", "VERY LIKELY R"],
    },
  },
  marks: [
    axisRadial({
      orient: "top", radius: 110, bands: true, bandWidth: 22,
      tickSize: 0, labelOffset: 18, fontSize: 8,
      channels: {
        theta: { field: "chance", scale: { range: [180, 0] } },
        // ColorBrewer RdBu is red→blue; reverse so D (left) is blue and R (right)
        // is red — a proper 7-class diverging categorical palette.
        fill: { field: "chance", scale: { scheme: "RdBu", reverse: true } },
      },
    }),
    needle({
      length: 95, fill: "#b91c1c",
      channels: {
        theta: {
          field: "chance",
          scale: { range: [180, 0] },
          edit: rotate({ pivot: "mark", fold: false, pick: "direct" }),
        },
      },
    }),
    text({
      fontSize: 14, dy: 32,
      channels: {
        text: { field: "chance" },
        textAnchor: { value: "middle" },
        lineAnchor: { value: "middle" },
      },
    }),
  ],
}));

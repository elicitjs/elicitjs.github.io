Line

A connected path over an ordered set of points, with a draggable handle on each. It is deliberately general — a you-draw-it curve, a multi-series line chart, and a connected scatter are the same mark along four orthogonal knobs: grouping (the series channel), ordering (the order channel, or the connect mode), editing (the edit on the handles), and creation (anchor / newSeries / draw). lineY/lineX fix the value axis; path defaults to connect: "sequence".

API reference

line(options) · lineY(options) · lineX(options) · path(options)

Import from elicit.plot. One non-interactive connector path per series, drawn under one draggable circle handle per datum. lineY/lineX pin the value axis; path defaults to connect: "sequence".

line({ channels, orientation, curve, connect, handles, handleSize, handleColor, edits, id }) → Feature
lineY(options) → Feature   // value on y (time series)
path(options) → Feature   // connect: "sequence"
Options
OptionTypeDefaultDescription
channelsobject{}Channel map — see Channels.
orientation'vertical' | 'horizontal'autoWhich axis the value runs along ('vertical' = y). Inferred from a band scale or the lone bound channel; lineY / lineX pin it.
channels.serieschannelautoThe column grouping points into lines. A channel, because it names a column. Defaults to fill’s field (then stroke’s), so a coloured chart auto-groups.
channels.orderchannel—The column each series is sorted by. Also a channel — a route’s stop number orders the line and encodes nothing, so there is no other channel to point at.
connect'domain' | 'sequence''domain'How points connect when no order channel is given: sorted by the domain axis, or as drawn. The mode only — it names no column.
curvestring'linear'Interpolation between handles (e.g. "catmullRom", "step").
handlesboolean | 'hit'truetrue draws a grabbable circle per datum. 'hit' keeps the grab target but draws nothing. false is neither drawn nor grabbable.
handleSizenumber5Pixel radius of each handle.
handleColorstringthemeHandle fill. Defaults to the theme’s handle colour.
edits, id——As on every mark. Line authoring edits live under edit.line.*.
Channels
ChannelTypeDescription
xlinear | band | timeDomain or value axis (per variant / inference).
ylinear | band | timeThe other axis; the value axis carries the handle edit.
strokeconst | fieldLine colour; a field here also becomes the default series grouping.
strokeWidth, opacityconst | fieldStandard style surface for the connector + handles.
Returns / emits

A feature with supportsSeries: true. Emits one path per series (pointerEvents:"none") plus one indexed circle handle per datum, each tagged with its series.

A line & its curve

lineY draws a value on y over a domain on x (the usual time series). curve sets the interpolation between handles.

curve: "catmullRom"

A smooth line through the points. Try "linear" or "step" for other shapes.

mount(Elicit({
  width: 400, height: 240,
  margins: { top: 14, right: 14, bottom: 26, left: 30 },
  data: [
    { x: 0, y: 40 }, { x: 1, y: 62 }, { x: 2, y: 48 },
    { x: 3, y: 78 }, { x: 4, y: 60 }, { x: 5, y: 84 },
  ],
  schema: {
    s: { type: "categorical" },  // the series key; declared so create() mints it
    x: { type: "quantitative", domain: [0, 5] },
    y: { type: "quantitative", domain: [0, 100] },
  },
  marks: [
    lineY({
      stroke: "#4f46e5", strokeWidth: 3, curve: "catmullRom",
      channels: {
        x: { field: "x" },
        y: { field: "y" },
      },
    }),
  ],
}))

You-draw-it (sweep)

Put edit: move(\{ pick: "sweep" \}) on the value channel for the NYT-style "you-draw-it" interaction: press and sweep horizontally to paint each point's y as the pointer crosses its column. The x positions stay fixed.

Sweep to draw the curve

The value channel carries a sweep; guide: true shows the paint guide.

mount(Elicit({
  width: 420, height: 260,
  margins: { top: 14, right: 14, bottom: 26, left: 30 },
  data: [
    { x: 0, y: 50 }, { x: 1, y: 50 }, { x: 2, y: 50 }, { x: 3, y: 50 },
    { x: 4, y: 50 }, { x: 5, y: 50 }, { x: 6, y: 50 }, { x: 7, y: 50 },
  ],
  schema: {
    s: { type: "categorical" },  // the series key; declared so create() mints it
    x: { type: "quantitative", domain: [0, 7] },
    y: { type: "quantitative", domain: [0, 100] },
  },
  marks: [
    lineY({
      stroke: "#4f46e5", strokeWidth: 3, curve: "catmullRom",
      channels: {
        x: { field: "x" },
        y: { field: "y",
             edit: move({ pick: "sweep", guide: true }) },
      },
    }),
  ],
}))
Try: Sweep left-to-right across the chart — or drag a single handle.

Hiding the handles

The per-point handles are optional. handles: false renders them invisible but keeps them for hit-testing, so the line stays fully editable — you just don't see the dots. handleSize sizes them when shown.

A clean line, still sweepable

handles: false hides the dots; the sweep edit still works.

mount(Elicit({
  width: 400, height: 240,
  margins: { top: 14, right: 14, bottom: 26, left: 30 },
  data: [
    { x: 0, y: 50 }, { x: 1, y: 50 }, { x: 2, y: 50 }, { x: 3, y: 50 },
    { x: 4, y: 50 }, { x: 5, y: 50 }, { x: 6, y: 50 }, { x: 7, y: 50 },
  ],
  schema: {
    s: { type: "categorical" },  // the series key; declared so create() mints it
    x: { type: "quantitative", domain: [0, 7] },
    y: { type: "quantitative", domain: [0, 100] },
  },
  marks: [
    lineY({
      stroke: "#7c3aed", strokeWidth: 3, curve: "catmullRom",
      handles: false,   // hide the anchor dots (still editable)
      channels: {
        x: { field: "x" },
        y: { field: "y",
             edit: move({ pick: "sweep", guide: true }) },
      },
    }),
  ],
}))
Try: Sweep across — no handles, but the line still responds.

Multiple lines (series)

A stroke field groups points into separate lines (Observable Plot’s z), so one mark holds many series and each auto-colours from the ordinal palette. A sweep locks onto the nearest line at drag-start and paints only that one.

Two series, swept independently

stroke: { field: "g" } both groups and colours the lines.

mount(Elicit({
  width: 420, height: 260,
  margins: { top: 14, right: 14, bottom: 26, left: 30 },
  data: [
    { g: "plan",   x: 0, y: 30 }, { g: "plan",   x: 1, y: 45 }, { g: "plan",   x: 2, y: 40 }, { g: "plan",   x: 3, y: 60 },
    { g: "actual", x: 0, y: 70 }, { g: "actual", x: 1, y: 62 }, { g: "actual", x: 2, y: 75 }, { g: "actual", x: 3, y: 68 },
  ],
  schema: {
    s: { type: "categorical" },  // the series key; declared so create() mints it
    x: { type: "quantitative", domain: [0, 3] },
    y: { type: "quantitative", domain: [0, 100] },
    g: { type: "categorical" },  // a group identifier, not an ordered scale
  },
  marks: [
    lineY({
      strokeWidth: 3, curve: "catmullRom",
      channels: {
        x: { field: "x" },
        y: { field: "y",
             edit: move({ pick: "sweep", guide: true }) },
        stroke: { field: "g" }, // groups AND colours the lines
      },
    }),
  ],
}))
Try: Sweep over one line to reshape it; the other stays put.

Connected scatter (connect: sequence)

With connect: "sequence" the points connect in creation order, not by domain — a connected scatter, or a free 2D path. Both axes carry a drag, so each point moves in 2D and the links follow. edit.line.anchor() adds a point to the path — near the line or far, it extends the same single line in click order, so the path stays one sequence.

A 2D path you can reshape

path defaults to connect: "sequence"; a 2D drag moves points, anchor extends the one path in click order.

mount(Elicit({
  width: 420, height: 300,
  margins: { top: 14, right: 14, bottom: 26, left: 30 },
  data: [
    { s: 0, x: 20, y: 30 }, { s: 0, x: 45, y: 70 },
    { s: 0, x: 70, y: 40 }, { s: 0, x: 85, y: 80 },
  ],
  schema: {
    s: { type: "categorical" },  // the series key; declared so create() mints it
    x: { type: "quantitative", domain: [0, 100] },
    y: { type: "quantitative", domain: [0, 100] },
  },
  marks: [
    path({
      stroke: "#0d9488", strokeWidth: 3,
      channels: {
        series: { field: "s" },
        x: { field: "x" },
        y: { field: "y" },
      },
      edits: [
        move({ channels: ["x", "y"], pick: "nearest", threshold: 40 }),
        edit.line.anchor({ into: "nearest", channels: ["x", "y"], series: "s", threshold: 80 }),
      ],
    }),
  ],
}))
Try: Drag a point anywhere, or click empty space to add the next anchor.

Draw from scratch (samples)

newSeries seeds a whole line at once — one anchor per sampled domain position (the scale's ticks by default, or a count, explicit list, or time interval), flat at the click value. Double-click empty space to drop a fresh line, then sweep it.

Double-click to seed, then sweep

edit.line.newSeries({ samples: 6 }) drops six evenly-spaced anchors at the click’s value.

mount(Elicit({
  width: 420, height: 300,
  margins: { top: 14, right: 14, bottom: 26, left: 30 },
  data: [],
  schema: {
    s: { type: "categorical" },  // the series key; declared so create() mints it
    x: { type: "quantitative", domain: [0, 10] },
    y: { type: "quantitative", domain: [0, 100] },
  },
  marks: [
    lineY({
      stroke: "#4f46e5", strokeWidth: 3, curve: "catmullRom",
      channels: {
        series: { field: "s" },
        x: { field: "x" },
        y: { field: "y",
             edit: move({ pick: "sweep", guide: true }) },
      },
      edits: [ edit.line.newSeries({ along: "x", value: "y", series: "s", samples: 6 }) ],
    }),
  ],
}))
Try: Double-click to drop a line, then sweep to shape it.

Draw it in one drag (draw)

draw authors lines by dragging, and it's edit-aware. On a domain-ordered line, a drag in empty space is you-draw-it from scratch — the pointer crossing each sample column lays that point down at the pointer value, so one stroke draws the curve. A later drag near the drawn line (within threshold) reshapes it with a sweep instead of making a new one; a drag farther away draws another. Pass into: "new" to always draw a fresh line.

Draw, then reshape

edit.line.draw({ samples: 8 }) on an empty line. First drag draws all eight points; a drag over the line reshapes it, a drag in empty space starts a new one.

mount(Elicit({
  width: 420, height: 300,
  margins: { top: 14, right: 14, bottom: 26, left: 30 },
  data: [],
  schema: {
    s: { type: "categorical" },  // the series key; declared so create() mints it
    x: { type: "quantitative", domain: [0, 10] },
    y: { type: "quantitative", domain: [0, 100] },
  },
  marks: [
    lineY({
      stroke: "#4f46e5", strokeWidth: 3, curve: "catmullRom",
      channels: {
        series: { field: "s" },
        x: { field: "x" },
        y: { field: "y" },
      },
      edits: [ edit.line.draw({ along: "x", value: "y", series: "s", samples: 8 }) ],
    }),
  ],
}))
Try: Press and drag to draw · drag over the line to reshape · drag elsewhere for a new line.

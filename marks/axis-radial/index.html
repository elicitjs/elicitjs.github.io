Radial axis

A composable radial axis: arc spine, ticks, labels, and optional coloured categorical bands. Sibling of axisX/axisY; reads the global theta scale — the polar angular position, which is what a needle encodes. (angle is a mark's rotation in place and has no axis.) Default orient is top (left → right through the top). Inert by default — pair with needle for interaction.

API reference

axisRadial(options)

Import from elicit.elements. A curved axis for a polar scale: an arc spine with ticks and labels, and optional coloured bands behind it.

A feature emitting background path/line/text nodes.

Continuous radial ticks

Spine + tick marks along a quantitative theta scale (top-facing by default).

Semi-circle axis

No needle — just the chrome. 0 on the left, 100 on the right.

mount(Elicit({
  width: 300, height: 180,
  margins: { top: 28, right: 20, bottom: 20, left: 20 },
  axes: false,
  data: [{ n: 50 }],
  schema: { n: { type: "quantitative", domain: [0, 100] } },
  marks: [
    axisRadial({
      orient: "top", radius: 90, ticks: 6, title: "score",
      channels: { theta: { field: "n", scale: { range: [180, 0] } } },
    }),
  ],
}));

Coloured categorical bands

Discrete domains get annular sectors, coloured by an ordinal fill.

Banded likelihood arc

Seven categories across a top-facing semicircle, coloured by reversed RdBu (blue→red).

mount(Elicit({
  width: 360, height: 210,
  margins: { top: 36, right: 64, bottom: 16, left: 64 },
  axes: false,
  overflow: "visible",   // long labels spill into the margin
  data: [{ chance: "TOSSUP" }],
  schema: {
    chance: {
      type: "ordinal",
      domain: ["VERY LIKELY D", "LIKELY D", "LEANING D", "TOSSUP",
               "LEANING R", "LIKELY R", "VERY LIKELY R"],
    },
  },
  marks: [
    axisRadial({
      orient: "top", radius: 110, bands: true, bandWidth: 28,
      labelOffset: 16, fontSize: 8,
      channels: {
        theta: { field: "chance", scale: { range: [180, 0] } },
        // RdBu is red→blue natively; reverse for the D→R (blue→red) reading.
        fill: { field: "chance", scale: { scheme: "RdBu", reverse: true } },
      },
    }),
  ],
}));

Tick + label customization

Ticks reuse the same helpers as Cartesian axes: ticks (count), tickValues (explicit), and tickFormat (d3-format string or function). Style labels with fontSize/labelFill and the spine with stroke.

Percent ticks at chosen values

Explicit tickValues, a percent tickFormat, and a custom label colour.

mount(Elicit({
  width: 300, height: 190,
  margins: { top: 30, right: 24, bottom: 16, left: 24 },
  axes: false,
  overflow: "visible",
  data: [{ p: 0.5 }],
  schema: { p: { type: "quantitative", domain: [0, 1] } },
  marks: [
    axisRadial({
      orient: "top", radius: 95,
      tickValues: [0, 0.25, 0.5, 0.75, 1],
      tickFormat: ".0%",
      labelFill: "#2563eb", fontSize: 11,
      stroke: "#93c5fd", tickSize: 8,
      channels: { theta: { field: "p", scale: { range: [180, 0] } } },
    }),
  ],
}));

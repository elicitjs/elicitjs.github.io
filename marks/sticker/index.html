Sticker

sticker() draws a rounded box with text inside, and sizes the box to the text: a long note wraps at maxWidth and grows taller instead of wider. Pair it with editText({ multiline: true }) to double-click and type into it. It is a preset over composite — an ordinary rect and text — so every channel, scale, edit and constraint works as elsewhere.

API reference

sticker(options)

Import from elicit.plot. A rounded box with text inside, sized by the text. A preset over composite, so it desugars into an ordinary rect and text.

sticker({ channels, padding, radius, maxWidth, minWidth, minHeight, lineHeight, fontFamily, format, table, edits, id }) → Feature[]
Options
OptionTypeDefaultDescription
channelsobject{}x/y place the box and are shared by both parts. text is the string it holds. Label channels (fontSize, textAnchor, dx, dy) go to the text; every other channel (fill, stroke, opacity, angle) goes to the box. width and height pin a dimension and turn auto-sizing off for that axis; a pinned width is also the width the text wraps at, so a note resized narrower re-flows and grows taller.
paddingnumber10Space between the text and the box’s edge, in px.
radiusnumber6Corner radius in px. Set 0 for square corners.
maxWidthnumber160The box stops growing here and the text wraps instead. Also the wrap width, so a long note gets taller rather than wider. A width channel replaces it on both counts.
minWidthnumber60Keeps an empty or one-word note from collapsing to nothing.
minHeightnumber0A floor for the box’s height, in px.
lineHeightnumber1.35 × fontSizeBaseline step between wrapped lines, in px.
fontSizenumber13Used to measure as well as to draw, so the box matches what is painted. A fontSize channel still reaches the label, but the box is measured at this value.
fontFamilystringthe theme’s fontMeasured with, when your page font differs from the theme’s.
formatstring | fnStringDisplay formatter for the text channel: a d3-format string, or (v) => string. Display-only — the column stays raw, so editText still writes the real value.
Returns / emits

Carries no edits of its own, like every mark. Put move({ channels: ["x", "y"], mode: "relative" }) on x and editText({ multiline: true }) in edits. Both land on the box: you drag and double-click the note, not its letters. Prefer mode: "relative" — an absolute move puts the box’s centre at the pointer, which snaps a note you grabbed by its corner.

editText(options)

Write a typed string back into the text channel’s field. Double-click opens an editor over the mark; Enter or clicking away commits, Escape cancels.

editText({ multiline, channels, when, stage }) → Edit
Options
OptionTypeDefaultDescription
multilinebooleanfalseUse a textarea, in which Enter inserts a newline and Cmd/Ctrl+Enter commits. Pair it with sticker, whose text wraps.
channelsstring[]["text"]Which channel’s field to write. The default is right almost always.

Sizing

The box is measured from the text channel string, at the fontSize and fontFamily it will be drawn in, plus padding on every side. Size does not live in your data.

maxWidth is both the ceiling and the wrap width. A longer note breaks onto more lines and the box gets taller. minWidth keeps a one-word note from collapsing.

State a width or height channel to pin that dimension instead:

sticker({ channels: { width: { value: 120 }, text: { field: "note" } } })

Auto-sizing stops for that axis only, so a pinned width still lets height follow the wrapped text. Size from the row with { fn }, or read a column of pixel widths with { field: "w", scale: null }.

A pinned width is also the wrap width, in place of maxWidth. Narrow a note and the text re-flows; with height still auto-sized, the box grows taller to fit.

Resizing

A width channel with a field behind it is a resize handle. The channel is in pixels, so give it an identity scale — a range matching the field's domain — and the column holds the box's width directly:

width: {
  field: "w",
  scale: { range: [70, 260] },
  edit: slide({ axis: "x", increase: "right", extent: 95, when: when.shift }),
}

slide moves the value by how far you drag, so the box does not jump when you press it. extent is the drag distance that sweeps the whole domain. The box grows about its centre, so half the domain's span (95 for a 190-wide domain) makes the edge you are dragging track the pointer.

Gate the two drags with when. A move on x and a slide on width both read horizontal travel, so without when.shift / when.noShift they fight over the same gesture.

Pin height the same way for a fixed-size card. Leave it off and height keeps following the text.

Resizable notes

Drag the width, and the text re-wraps to fit.

mount(Elicit({
  width: 460, height: 300,
  margins: { top: 20, right: 20, bottom: 20, left: 20 },
  axes: false,
  schema: {
    note: { type: "categorical", open: true },
    w: { type: "quantitative", domain: [70, 260] },
    x: { type: "quantitative", domain: [0, 100] },
    y: { type: "quantitative", domain: [0, 100] },
  },
  data: [
    { note: "Shift-drag my edge sideways. The text re-wraps to whatever width I end up.", w: 170, x: 32, y: 62 },
    { note: "Narrow notes get taller.", w: 100, x: 72, y: 28 },
  ],
  marks: [
    sticker({
      fill: "#fde68a",
      stroke: "#00000022",
      maxWidth: 260,
      edits: [editText({ multiline: true })],
      channels: {
        x: {
          field: "x",
          edit: move({ channels: ["x", "y"], mode: "relative", when: when.noShift }),
        },
        y: { field: "y" },
        width: {
          field: "w",
          scale: { range: [70, 260] },
          edit: slide({ axis: "x", increase: "right", extent: 95, when: when.shift }),
        },
        text: { field: "note" },
      },
    }),
  ],
}));
Try: Shift-drag a note sideways to resize it — the text re-wraps and the box gets taller as it narrows. Drag without Shift to move it, and double-click to retype.

Typing

editText() writes what you type back into the text channel's field. Put it in edits:

sticker({
  edits: [editText({ multiline: true })],
  channels: { x: { field: "x" }, y: { field: "y" }, text: { field: "note" } },
})

Double-click a note to open an editor filling the box. multiline: true makes it a textarea: Enter inserts a newline, and Cmd/Ctrl+Enter or clicking away commits. Escape cancels either way. Without it you get a single-line field where Enter commits.

Both the drag and the double-click land on the box, not the letters, so you can pick up a note by any part of it — including the gaps between words.

Typing is only wired in the SVG renderer. Under CanvasRenderer a sticker draws and drags, but double-click does nothing.

Editing a board

Nothing here is sticker-specific. The universal edits do the rest:

  • move({ channels: ["x", "y"], mode: "relative" }) on x drags a note. Use mode: "relative" on anything with area: it moves by how far you drag, keeping the grab point under the pointer. The default "absolute" puts the note's centre at the pointer, which snaps a big box the moment you press it.
  • create() in edits mints one where you click. Give it defaults so a new note arrives with a colour and a placeholder.
  • remove({ when: when.alt }) deletes the note under the pointer.
  • cycle() on fill steps through the colours in that field's domain.

Sticky notes

Boxes sized by what you type.

mount(Elicit({
  width: 460, height: 300,
  margins: { top: 20, right: 20, bottom: 20, left: 20 },
  axes: false,
  schema: {
    note: { type: "categorical", open: true },
    tone: { type: "categorical", domain: ["#fde68a", "#bbf7d0", "#bfdbfe"] },
    x: { type: "quantitative", domain: [0, 100] },
    y: { type: "quantitative", domain: [0, 100] },
  },
  data: [
    { note: "Drag me", tone: "#fde68a", x: 25, y: 75 },
    { note: "Double-click to rewrite. Long notes wrap and the box grows.", tone: "#bbf7d0", x: 70, y: 45 },
    { note: "Click empty space for a new one", tone: "#bfdbfe", x: 25, y: 22 },
  ],
  marks: [
    sticker({
      stroke: "#00000022",
      maxWidth: 140,
      edits: [
        editText({ multiline: true }),
        create({ defaults: { note: "New note", tone: "#fde68a" } }),
        remove({ when: when.alt }),
      ],
      channels: {
        x: { field: "x", edit: move({ channels: ["x", "y"], mode: "relative" }) },
        y: { field: "y" },
        text: { field: "note" },
        fill: { field: "tone", scale: null, edit: cycle() },
      },
    }),
  ],
}));
Try: Drag a note. Double-click one and type — Enter makes a new line, Cmd/Ctrl+Enter commits, and the box resizes. Click a note to recolour it,click empty space to add one, and Alt-click to delete.

Diagram board

A board you draw on is a network schema with a sticker over the nodes and a link over the links — there is no diagram mark. Draw link() first so connectors sit behind the boxes.

Give the connectors curve: "orthogonal" and tell them how big a note is, and each one leaves a box square out of one of its edges rather than crossing a corner. A sticker measures its box from its own text, so measure it the same way with noteBox and pass the options you gave the sticker. inset is then the gap between the edge and the line, and cornerRadius rounds the turns.

connect and move both fire on a drag from a box, so split them with when.shift / when.noShift. Deleting a box drops its connectors: source and target are ref columns, so a link naming a missing node is removed from the dataset. See Network for the topology edits and connector styles.

Flowchart

Boxes you type into, connectors you drag, flip and restyle.

mount(Elicit({
  width: 520, height: 360,
  margins: { top: 24, right: 24, bottom: 24, left: 24 },
  axes: false,
  schema: {
    structure: "network",
    tables: {
      steps: {
        role: "nodes",
        fields: {
          id: { type: "categorical", key: true, open: true },
          label: { type: "categorical", open: true },
          x: { type: "quantitative", domain: [0, 100] },
          y: { type: "quantitative", domain: [0, 100] },
        },
      },
      flows: {
        role: "links",
        directed: true,
        fields: {
          source: { type: "ref" },
          target: { type: "ref" },
          kind: { type: "categorical", domain: ["orthogonal", "bezier"] },
        },
      },
    },
  },
  data: {
    steps: [
      { id: "s1", label: "Draft the question", x: 22, y: 82 },
      { id: "s2", label: "Pilot it with five readers", x: 74, y: 60 },
      { id: "s3", label: "Ship", x: 30, y: 18 },
    ],
    flows: [
      { source: "s1", target: "s2", kind: "orthogonal" },
      { source: "s2", target: "s1", kind: "orthogonal" },
      { source: "s2", target: "s3", kind: "bezier" },
    ],
  },
  marks: [
    link({
      cornerRadius: 8,
      inset: 6,
      stroke: "#94a3b8",
      strokeWidth: 1.5,
      channels: {
        curve: { field: "kind" },
        // The box each connector docks to. A sticker sizes itself from its text,
        // so `noteBox` measures the same note the same way.
        nodeWidth: { fn: (d) => noteBox(d.label, { maxWidth: 130 }).width },
        nodeHeight: { fn: (d) => noteBox(d.label, { maxWidth: 130 }).height },
      },
      edits: [
        edit.network.reverse({ when: when.alt }),
        cycle({ channels: ["curve"], when: when.noAlt }),
      ],
    }),
    sticker({
      fill: "#fef3c7",
      stroke: "#f59e0b",
      maxWidth: 130,
      radius: 8,
      edits: [
        editText({ multiline: true }),
        edit.network.connect({ when: when.shift, defaults: { kind: "orthogonal" } }),
        create({ defaults: { label: "New step" } }),
        remove({ when: when.alt }),
      ],
      channels: {
        x: { field: "x", edit: move({ channels: ["x", "y"], mode: "relative", when: when.noShift }) },
        y: { field: "y" },
        text: { field: "label" },
      },
    }),
  ],
}));
Try: Double-click a box and type — Enter makes a new line, Cmd/Ctrl+Enter commits, and the box grows to fit. Shift-drag from one box to another to connect them. Drag a box past another and the connectors re-route to the edges now facing. Click a connector to switch it between an elbow and a curve, and Alt-click one to reverse it. Click empty space for a new box, and Alt-click a box to delete it — its connectors go too.

Notes on a scale

A sticker places itself through the same scales as any other mark, so point x at a categorical field and the notes sit in columns. move inverts the drag back through that band scale, so dropping a note in another column writes the new category into the row.

Which lane a note ends in is the belief — getData() returns it as lane. Sort within a lane by pointing y at a quantitative field, as here with rank.

Lanes

A band scale on x, so a drag re-files a card.

mount(Elicit({
  width: 480, height: 320,
  margins: { top: 24, right: 16, bottom: 30, left: 16 },
  axes: { x: {}, y: false },
  schema: {
    note: { type: "categorical", open: true },
    lane: { type: "categorical", domain: ["Now", "Next", "Later"] },
    rank: { type: "quantitative", domain: [0, 100] },
  },
  data: [
    { note: "Measure the text", lane: "Now", rank: 80 },
    { note: "Wrap long notes", lane: "Now", rank: 40 },
    { note: "Resize a note by its edge", lane: "Next", rank: 65 },
    { note: "Wire notes together", lane: "Later", rank: 55 },
  ],
  marks: [
    grid({ channel: "x" }),
    sticker({
      fill: "#e0f2fe",
      stroke: "#0284c7",
      maxWidth: 120,
      edits: [
        editText({ multiline: true }),
        create({ defaults: { note: "New card" } }),
        remove({ when: when.alt }),
      ],
      channels: {
        x: { field: "lane", edit: move({ channels: ["x", "y"], mode: "relative" }) },
        y: { field: "rank" },
        text: { field: "note" },
      },
    }),
  ],
}));
Try: Drag a card into another lane — it snaps to the column and the row’s lane changes. Double-click to retype, click empty space to add a card, and Alt-click to delete.

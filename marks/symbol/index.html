Symbol & Emoji

The symbol channel maps a category to a glyph — an emoji or a unicode shape — exactly the way fill maps a category to a colour. It is not a mark: any shape mark (point, dotStack, waffle) renders the glyph in place of its circle/rect. The elicited value is still the category; the glyph is its encoding, edited with cycle() / legend().

API reference

channels.symbol

A category → glyph map through an ordinal scale. Add it to any shape mark. Give it glyphs with scale: { range: [...] } or a named scale: { scheme: 'faces' }. Non-positional and non-invertible — a drag can't set a glyph, so it's edited via cycle/legend/create.

symbol: { field, scale: { range | scheme }, edit? }
Options
OptionTypeDefaultDescription
scale.rangestring[]unicode shapesThe glyph palette. Defaults to ●■▲◆★… when omitted.
scale.schemestring—Named glyph set: 'faces', 'faces5', 'hearts', 'weather', 'arrows', 'shapes'.
sizenumbermark defaultThe mark's radius still sets the glyph's px extent, so a glyph point and a circle point match.
Channels
ChannelTypeDescription
symbolordinalField → glyph. Range is a glyph array (scale: { range: ["😢","😐","😊"] }) or a scheme.
Returns / emits

Nothing on its own — it changes how a host mark draws each datum.

Emoji points — click to cycle

A mood scatter: the y position and the glyph both encode mood. A cycle() on the symbol channel advances the category on click — the face changes and the point hops to its new row, because an edit is the inverse of encoding.

Mood over the week

symbol maps the ordinal mood to a face; cycle() advances it on click.

mount(Elicit({
  width: 380, height: 250,
  margins: { top: 16, right: 16, bottom: 30, left: 64 },
  data: [
    { day: "Mon", mood: "ok" },   { day: "Tue", mood: "good" },
    { day: "Wed", mood: "bad" },  { day: "Thu", mood: "good" },
    { day: "Fri", mood: "great" },
  ],
  schema: {
    day:  { type: "categorical", domain: ["Mon","Tue","Wed","Thu","Fri"] },
    mood: { type: "ordinal", domain: ["bad","ok","good","great"] },
  },
  marks: [
    point({
      size: 15,
      channels: {
        x: { field: "day" },
        y: { field: "mood" },
        symbol: {
          field: "mood",
          scale: { range: ["😢","😐","🙂","😄"] },
          edit: cycle(),
        },
      },
    }),
  ],
}))
Try: Click a face to cycle its mood.

One fixed glyph — no mapping

You don't need a scale to use a glyph. The symbol: '⚽' shorthand pins one glyph on every point — it desugars to a constant channel and skips the scale, exactly like fill: 'red'. Here the elicited value is goals: the balls are pure identity, and you drag one up or down to set that stage's total.

World Cup goals

A constant symbol: '⚽' — one glyph for every point, no scale. The elicited value is goals; drag a ball up or down to set it.

mount(Elicit({
  width: 420, height: 260,
  margins: { top: 16, right: 16, bottom: 30, left: 40 },
  data: [
    { stage: "Group", goals: 3 },
    { stage: "R16",   goals: 2 },
    { stage: "QF",    goals: 2 },
    { stage: "SF",    goals: 1 },
    { stage: "Final", goals: 2 },
  ],
  schema: {
    stage: { type: "categorical", domain: ["Group","R16","QF","SF","Final"] },
    goals: { type: "quantitative", domain: [0, 6] },
  },
  marks: [
    point({
      size: 15,
      symbol: "⚽",                       // one glyph, no mapping — pure identity
      channels: {
        x: { field: "stage" },
        y: { field: "goals", edit: move() },
      },
    }),
  ],
}))
Try: Drag a ⚽ up or down to change that stage's goals.

Emoji tokens — drop and remove

A constant symbol shorthand makes every token the same glyph. Because the glyph is just how the token draws, create / remove work unchanged — a ⭐ star-rating counter.

Star tokens

dotStack of ⭐ tokens; click a slot to add, click a star to remove.

mount(Elicit({
  width: 380, height: 240,
  margins: { top: 16, right: 16, bottom: 30, left: 30 },
  data: [ { rating: 3 }, { rating: 3 }, { rating: 5 }, { rating: 4 } ],
  schema: { rating: { type: "ordinal", domain: [1, 2, 3, 4, 5] } },
  constraints: [ count({ max: 24 }) ],
  marks: [
    dotStack({
      symbol: "⭐", size: 12,
      channels: { x: { field: "rating" } },
      edits: [ create({ gesture: "click", channels: ["x"] }), remove() ],
    }),
  ],
}))
Try: Click a column to add a ⭐, click a ⭐ to remove it.

Emoji waffle — count in glyphs

A symbol channel turns every waffle cell into that category's glyph, so a quantity is literally countable in 🍎. Drag to fill; the empty cells stay faint but grabbable.

Fruit basket

Each category's cells render its emoji; edit.waffle.fill drags the count.

mount(Elicit({
  width: 380, height: 280,
  margins: { top: 16, right: 16, bottom: 30, left: 30 },
  data: [
    { fruit: "apples",   n: 6 },
    { fruit: "bananas",  n: 4 },
    { fruit: "cherries", n: 9 },
  ],
  schema: {
    fruit: { type: "categorical", domain: ["apples","bananas","cherries"] },
    n:     { type: "quantitative", domain: [0, 12] },
  },
  constraints: [ snap({ step: 1 }) ],
  marks: [
    waffleY({
      channels: {
        x: { field: "fruit" },
        count: { field: "n", edit: edit.waffle.fill() },
        symbol: { field: "fruit", scale: { range: ["🍎","🍌","🍒"] } },
      },
    }),
  ],
}))
Try: Drag up a column to change its count.

A glyph legend / picker

legendSymbol({ edit: edit.legend.category() }) draws a row of glyphs you click to set the category — the same legend mark as a colour legend, drawn with the glyphs themselves instead of chips.

Pick a weather

A single-row belief whose glyph is set from the legend row.

mount(Elicit({
  width: 360, height: 240,
  margins: { top: 16, right: 16, bottom: 16, left: 16 },
  data: [ { sky: "cloudy" } ],
  schema: { sky: { type: "ordinal", domain: ["sunny","partly","cloudy","rain","storm"] } },
  axes: false,
  marks: [
    point({
      size: 40,
      channels: {
        x: { value: 60 }, y: { value: 100 },
        symbol: { field: "sky", scale: { scheme: "weather" } },
      },
    }),
    // A glyph legend that doubles as a picker: legendSymbol draws the row of
    // glyphs, edit.legend.category() makes each one click-to-set the category.
    legendSymbol({ anchor: "bottom", swatchSize: 22, edit: edit.legend.category() }),
  ],
}))
Try: Click a glyph in the legend to set today's weather.

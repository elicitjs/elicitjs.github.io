Text

A per-datum label, as in Observable Plot's text. It places a string at a position (x, y); text/fontSize/textAnchor/lineAnchor/dx/dy are read as-is — a field or a constant — angle is degrees, and format is a d3-format string or function (display-only). A text mark is editable like any other: drag to reposition, drag a value to update a numeric readout, cycle() a label, rotate() it, or editText() to retype its content.

API reference

text(options) · textX(options) · textY(options)

Import from elicit.plot. text positions from x AND y; textX / textY are 1-D labels along one axis (the other parks at centre).

text({ channels, orientation, format, wrap, lineHeight, edits, id }) → Feature
textX(options) → Feature   // value on x
textY(options) → Feature   // value on y
Options
OptionTypeDefaultDescription
channelsobject{}Channel map. See Channels.
orientation'vertical' | 'horizontal'autoWhich axis the value runs along ('vertical' = y). Inferred from a band scale or the lone bound channel; textY / textX pin it.
text, fontSize, textAnchor, lineAnchor, dx, dyshorthand—Constant shorthands, e.g. text({ dy: -8, lineAnchor: "bottom" }).
formatstring | fnStringDisplay formatter: a d3-format string (e.g. ".1f") or (v) => string. Display-only — the field stays raw. Helpers live on format (format.number, format.percent, …).
wrapnumber | fn—Wrap the label at this pixel width. A function (d, i, data) => number gives a per-datum width, for a label that has to fit the box it sits in.
lineHeightnumber1.35 × fontSizePixel step between wrapped lines.
editsEdit[]—Mark-level edits; per-channel edits live in channels[ch].edit.
Channels
ChannelTypeDescription
x / ylinear | bandPosition. A missing axis parks the label at that dimension’s centre.
textfield | constThe value to draw (raw — no scale; passed through format).
fontSizefield | constSize in px, raw.
textAnchorfield | constHorizontal anchor: start·middle·end.
lineAnchorfield | constVertical anchor: top·middle·bottom (maps to SVG dominant-baseline).
dx / dyfield | constPixel offsets from the encoded (x, y). Visual-only — drag still inverts the pointer through the scale.
anglefield | constRotation in degrees (scaled when a scale is declared, so rotate() is an exact inverse).
fill, opacityconst | fieldStandard style surface.
Returns / emits

A feature emitting one text per datum.

Labels from data

x/y position the label; text is its string. Offset and anchor keep it clear of the mark it labels.

A labelled scatter

point for the dots, text for the labels above them — dy + lineAnchor park the string above the point.

mount(Elicit({
  width: 360, height: 260,
  margins: { top: 16, right: 16, bottom: 28, left: 34 },
  data: [
    { gdp: 3, life: 6, name: "Ada" },
    { gdp: 6, life: 8, name: "Grace" },
    { gdp: 8, life: 4, name: "Alan" },
  ],
  schema: {
    gdp:  { type: "quantitative", domain: [0, 10] },
    life: { type: "quantitative", domain: [0, 10] },
    name: { type: "categorical", domain: ["Ada", "Grace", "Alan"] },
  },
  marks: [
    point({ fill: "#4f46e5",
      channels: { x: { field: "gdp" }, y: { field: "life" } } }),
    text({ fontSize: 12, dy: -10, lineAnchor: "bottom",
      channels: {
        x: { field: "gdp" }, y: { field: "life" },
        text: { field: "name" },
      } }),
  ],
}))

Formatted numeric labels

format is display-only (a d3-format string or a helper from format.*). The field stays the raw number, so a later drag still inverts correctly.

mount(Elicit({
  width: 360, height: 240,
  margins: { top: 16, right: 16, bottom: 28, left: 34 },
  data: [
    { cat: "A", n: 0.42 },
    { cat: "B", n: 0.75 },
    { cat: "C", n: 0.18 },
  ],
  schema: {
    cat: { type: "categorical", domain: ["A", "B", "C"] },
    n:   { type: "quantitative", domain: [0, 1] },
  },
  marks: [
    barY({ fill: "#0d9488",
      channels: { x: { field: "cat" }, y: { field: "n" } } }),
    text({ fontSize: 12, dy: -6, lineAnchor: "bottom",
      format: format.percent(".0%"),
      channels: {
        x: { field: "cat" }, y: { field: "n" },
        text: { field: "n" },
      } }),
  ],
}))

Line chart with value labels

lineY draws the series; text sits on the same (x, y) with dy above each point.

mount(Elicit({
  width: 400, height: 260,
  margins: { top: 20, right: 16, bottom: 28, left: 34 },
  data: [
    { t: 0, n: 40 }, { t: 1, n: 62 }, { t: 2, n: 48 },
    { t: 3, n: 78 }, { t: 4, n: 60 }, { t: 5, n: 84 },
  ],
  schema: {
    t: { type: "quantitative", domain: [0, 5] },
    n: { type: "quantitative", domain: [0, 100] },
  },
  marks: [
    lineY({
      stroke: "#4f46e5", strokeWidth: 2.5, curve: "catmullRom",
      channels: { x: { field: "t" }, y: { field: "n" } },
    }),
    text({
      fontSize: 11, dy: -10, lineAnchor: "bottom",
      fill: "#4f46e5", format: ".0f",
      channels: {
        x: { field: "t" }, y: { field: "n" },
        text: { field: "n" },
      },
    }),
  ],
}))

Editing labels

A direct-pick edit makes a label interactive. Reuse the universal edits — nothing text-specific — or editText() to retype the content.

Drag to reposition

Mark-level move({ channels: ["x","y"] }) moves the label; writes x/y back through the scales. (Do not put <code class="inline">edit</code> as a channel key — attach it on a channel or via <code class="inline">edits</code>.)

mount(Elicit({
  width: 360, height: 240,
  margins: { top: 16, right: 16, bottom: 28, left: 34 },
  data: [
    { x: 3, y: 4, label: "drag me" },
    { x: 6, y: 7, label: "and me" },
  ],
  schema: {
    x: { type: "quantitative", domain: [0, 10] },
    y: { type: "quantitative", domain: [0, 10] },
    label: { type: "categorical", domain: ["drag me", "and me"] },
  },
  marks: [
    text({ fontSize: 13, fill: "#2563eb",
      channels: {
        x: { field: "x" }, y: { field: "y" },
        text: { field: "label" },
      },
      edits: [ move({ channels: ["x", "y"] }) ],
    }),
  ],
}))
Try: Drag a label to move it.

Draggable numeric readout

The label is the value itself: text and y read the same field, and move() on y rewrites it — so the number updates as you drag. format keeps the display tidy.

mount(Elicit({
  width: 360, height: 260,
  margins: { top: 16, right: 16, bottom: 28, left: 40 },
  data: [ { cat: "A", n: 40 }, { cat: "B", n: 70 } ],
  schema: {
    cat: { type: "categorical", domain: ["A", "B"] },
    n:   { type: "quantitative", domain: [0, 100] },
  },
  marks: [
    text({ fontSize: 16, fill: "#0d9488", format: ".1f",
      channels: {
        x: { field: "cat" },
        y: { field: "n", edit: move() },
        text: { field: "n" },
      } }),
  ],
}))
Try: Drag the number up or down.

Type to edit content

editText() wires double-click-to-retype: an inline input opens, Enter commits, Esc cancels.

mount(Elicit({
  width: 360, height: 220,
  margins: { top: 16, right: 16, bottom: 28, left: 34 },
  data: [
    { x: 3, y: 5, label: "double-click" },
    { x: 7, y: 3, label: "me too" },
  ],
  schema: {
    x: { type: "quantitative", domain: [0, 10] },
    y: { type: "quantitative", domain: [0, 10] },
    label: { type: "categorical" },
  },
  marks: [
    text({ fontSize: 14, fill: "#7b2d8b",
      channels: {
        x: { field: "x" }, y: { field: "y" },
        text: { field: "label", edit: editText() },
      } }),
  ],
}))
Try: Double-click a label, type, and press Enter.

Drag and retype together

Mark-level drag plus editText on the text channel: drag repositions, double-click retypes.

mount(Elicit({
  width: 360, height: 220,
  margins: { top: 16, right: 16, bottom: 28, left: 34 },
  data: [
    { x: 3, y: 5, label: "move me" },
    { x: 7, y: 3, label: "rename me" },
  ],
  schema: {
    x: { type: "quantitative", domain: [0, 10] },
    y: { type: "quantitative", domain: [0, 10] },
    label: { type: "categorical" },
  },
  marks: [
    text({ fontSize: 14, fill: "#b45309",
      channels: {
        x: { field: "x" }, y: { field: "y" },
        text: { field: "label", edit: editText() },
      },
      edits: [ move({ channels: ["x", "y"] }) ],
    }),
  ],
}))
Try: Drag to move; double-click to rename.

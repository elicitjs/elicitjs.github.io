Waffle

Like a bar, a waffle shows a quantity for a category — but subdivides the block into a grid of cells where one cell is a fixed quantity (unit), so a reader can literally count amounts and a gesture can pick a proportion cell-by-cell. value / unit cells fill; cells sit multiple across the band, so each row spans multiple · unit and its band is read from the value scale — rows land on axis ticks and the filled height matches the value. Pair with snap (step = unit) to land drags on whole cells.

API reference

waffle(options) · waffleY(options) · waffleX(options)

Import from elicit.plot. waffleY grows blocks upward (category on x), waffleX rightward (category on y). Bare waffle reads the direction from the channel map: the category's axis is the band, and count runs along the other one.

waffleY({ channels, orientation, unit, multiple, shape, showEmpty, emptyFill, gap, edits, id }) → Feature

A feature emitting one cell node (rect or circle) per cell; every cell carries the datum, so the whole block is one drag/click target.

Counting quantities

A waffle over four categories — each cell is a fixed count (here 10), so amounts read exactly: count the cells and multiply by the unit. Rows land on the y-axis ticks.

Fruit counts

Static waffle; y domain 0–320, one cell = 10 fruit (32 cells tall), multiple auto-picked square.

const cats = ["apples","bananas","oranges","pears"];
mount(Elicit({
  width: 460, height: 300,
  margins: { top: 16, right: 12, bottom: 28, left: 34 },
  data: [
    { cat: "apples", value: 210 }, { cat: "bananas", value: 200 },
    { cat: "oranges", value: 310 }, { cat: "pears", value: 40 },
  ],
  schema: {
    cat:   { type: "categorical", domain: cats },
    value: { type: "quantitative", domain: [0, 320] },
  },
  scales: { x: { type: "band" } },
  marks: [
    waffleY({
      fill: "#4f46e5",
      channels: {
        x: { field: "cat" },
        count: { field: "value" },
      },
      unit: 10,
    }),
  ],
}));

Picking a proportion

One category on a 0–1 axis; each cell is 1/50, so 50 cells fill the block. edit.waffle.fill() fills up to the exact cell under the pointer — click or drag — so the value is always a whole number of cells.

Proportion picker

click or drag; unit = 1/50 makes 50 countable cells, edit.waffle.fill lands exactly on the cell you point at.

mount(Elicit({
  width: 220, height: 300,
  margins: { top: 16, right: 12, bottom: 24, left: 34 },
  data: [{ cat: "belief", value: 0.4 }],
  onChange: (d) => console.log("proportion:", d[0].value.toFixed(2)),
  schema: {
    cat:   { type: "categorical", domain: ["belief"] },
    value: { type: "quantitative", domain: [0, 1] },
  },
  scales: { x: { type: "band" } },
  marks: [
    waffleY({
      fill: "#0ea5e9",
      unit: 1/50,
      channels: {
        x: { field: "cat" },
        count: { field: "value", edit: edit.waffle.fill() },
      },
      // click sets the count to the clicked cell too
      edits: [ edit.waffle.fill({ channels: ["count"], gesture: "click" }) ],
    }),
  ],
}));
Try: click a cell, or drag up/down.

Dots, click-to-set & hidden track

Cells can be circles (shape: "circle") — uniform squares that touch, packed to fill the band width and height. A click-gesture edit sets the count to the clicked cell in one tap, and showEmpty: false hides the track while keeping it grabbable.

Click a dot to set the count

circle cells, one = 5; uniform dots pack tightly (gap: 0). Click any dot to fill up to and including it, or drag.

mount(Elicit({
  width: 240, height: 300,
  margins: { top: 16, right: 12, bottom: 24, left: 34 },
  data: [{ cat: "count", value: 45 }],
  onChange: (d) => console.log("count:", d[0].value),
  schema: {
    cat:   { type: "categorical", domain: ["count"] },
    value: { type: "quantitative", domain: [0, 100] },
  },
  scales: { x: { type: "band" } },
  marks: [
    waffleY({
      fill: "#16a34a",
      shape: "circle",
      unit: 5,
      gap: 0,
      channels: {
        x: { field: "cat" },
        count: { field: "value", edit: edit.waffle.fill() },   // drag to fill
      },
      edits: [ edit.waffle.fill({ channels: ["count"], gesture: "click" }) ], // click to set
    }),
  ],
}));
Try: click a dot, or drag up/down.

Small counts (unit = 1)

With unit: 1 each cell is exactly one item, so small counts read directly — one cell means one. The grid is only as wide as it needs to be, never wider than the band, and is centred, so a category of 1 shows a single cell.

Tallies of 1–6

one cell = one item; counts of 1, 3, 6, 2 — count the cells directly.

const cats = ["A","B","C","D"];
mount(Elicit({
  width: 460, height: 260,
  margins: { top: 16, right: 12, bottom: 28, left: 28 },
  data: [
    { cat: "A", value: 1 }, { cat: "B", value: 3 },
    { cat: "C", value: 6 }, { cat: "D", value: 2 },
  ],
  schema: {
    cat:   { type: "categorical", domain: cats },
    value: { type: "quantitative", domain: [0, 6] },
  },
  scales: { x: { type: "band" } },
  marks: [
    waffleY({
      fill: "#d97706",
      shape: "circle",
      unit: 1,
      gap: 0,
      channels: { x: { field: "cat" }, count: { field: "value" } },
    }),
  ],
}));

The count axis

A waffle's magnitude is the count channel, and it sits on a count axis — not on y. "How many cells" and "how far up the y axis" are different questions about different quantities, so they get different domains; a waffle and a bar in one chart never union theirs.

The axis is opt-in. Ask for it with axes: \{ count: true \}. It defaults off for the same reason legends do — it reserves layout space for a scale the mark already makes countable by eye — and it reports data units, so it agrees with the column that fed it.

unit is the exchange rate: one cell is worth unit of the field, so with the default unit: 1 the column value is the number of cells. Pick a unit that divides the declared domain; when it doesn't, the top cell is a fraction and the mark says so.

A count axis

axes: { count: true } — one cell is 10, so the 320 domain spans 32 cells.

const cats = ["apples","bananas","oranges","pears"];
mount(Elicit({
  width: 460, height: 300,
  margins: { top: 16, right: 12, bottom: 28, left: 44 },
  // The count axis is opt-in: it reserves layout space for a scale these marks
  // already make countable by eye, so it sits with `legends`, not with x/y.
  axes: { count: true },
  data: [
    { cat: "apples", value: 210 }, { cat: "bananas", value: 200 },
    { cat: "oranges", value: 310 }, { cat: "pears", value: 40 },
  ],
  schema: {
    cat:   { type: "categorical", domain: cats },
    value: { type: "quantitative", domain: [0, 320] },
  },
  scales: { x: { type: "band" } },
  marks: [
    waffleY({
      fill: "#4f46e5",
      channels: {
        x: { field: "cat" },
        // The magnitude is `count`, on a count axis of its own — not `y`.
        count: { field: "value" },
      },
      unit: 10,          // one cell is worth 10, so 320 spans 32 cells
    }),
  ],
}));

Orientation

Put the category on y and the blocks grow rightward instead of up. waffleY and waffleX force a direction; bare waffle takes it from the channel map, since the category's axis is the band and count runs along the other one. orientation: "horizontal" | "vertical" is the explicit form, the same option bar takes.

Blocks that grow rightward

waffleX with the category on y; the count axis sits at the bottom.

const cats = ["apples","bananas","oranges","pears"];
mount(Elicit({
  width: 460, height: 260,
  margins: { top: 16, right: 16, bottom: 28, left: 72 },
  axes: { count: true },
  data: [
    { cat: "apples", value: 210 }, { cat: "bananas", value: 200 },
    { cat: "oranges", value: 310 }, { cat: "pears", value: 40 },
  ],
  schema: {
    cat:   { type: "categorical", domain: cats },
    value: { type: "quantitative", domain: [0, 320] },
  },
  scales: { y: { type: "band" } },
  marks: [
    waffleX({
      fill: "#4f46e5",
      channels: {
        // The category is on y, so the count runs along x.
        y: { field: "cat" },
        count: { field: "value" },
      },
      unit: 10,
    }),
  ],
}));

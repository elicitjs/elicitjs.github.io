Bar

A rectangular mark: one axis is a categorical band (the position), the other a linear value drawn as length from a baseline (or an explicit start/end span via x1/x2 or y1/y2). bar auto-detects orientation from which axis is a band; barY forces vertical, barX horizontal. For rectangles that span both axes (heatmap cells, 2-D regions), use rect + brushRect() instead.

API reference

bar(options) · barY(options) · barX(options)

Import from elicit.plot. bar infers orientation from which axis is a band; barY forces vertical, barX horizontal. All three share these options.

bar({ channels, orientation, edits, id }) → Feature
barY(options) → Feature   // orientation: "vertical"
barX(options) → Feature   // orientation: "horizontal"

Band × value

The band axis slots the bars; the linear axis sets their length from a baseline.

A vertical bar chart

x band of categories, y linear value.

mount(Elicit({
  width: 380, height: 240,
  margins: { top: 16, right: 16, bottom: 28, left: 34 },
  data: [
    { cat: "A", n: 30 }, { cat: "B", n: 55 },
    { cat: "C", n: 22 }, { cat: "D", n: 44 },
  ],
  schema: {
    cat: { type: "categorical", domain: ["A", "B", "C", "D"] },
    n:   { type: "quantitative", domain: [0, 60] },
  },
  marks: [
    bar({
      fill: "#4f46e5",
      channels: {
        x: { field: "cat" },
        y: { field: "n" },
      },
    }),
  ],
}))

Colour by a field

fill: { field: "kind" } tints each bar through the ordinal palette.

mount(Elicit({
  width: 340, height: 240,
  margins: { top: 14, right: 14, bottom: 26, left: 30 },
  data: [
    { cat: "A", n: 34, kind: "low" },  { cat: "B", n: 58, kind: "high" },
    { cat: "C", n: 22, kind: "low" },  { cat: "D", n: 47, kind: "high" },
  ],
  schema: {
    cat:  { type: "categorical", domain: ["A", "B", "C", "D"] },
    n:    { type: "quantitative", domain: [0, 60] },
    kind: { type: "categorical", domain: ["low", "high"] },
  },
  marks: [
    bar({
      channels: {
        x: { field: "cat" },
        y: { field: "n" },
        fill: { field: "kind" },
      },
    }),
  ],
}))

Horizontal bars (barX)

Put the band on y and the value on x, and the bars run horizontally. barX forces this orientation; bar would infer it from the band axis.

barX — value on x

y is the category band, x the linear value drawn rightward from the baseline.

mount(Elicit({
  width: 380, height: 240,
  margins: { top: 14, right: 16, bottom: 26, left: 60 },
  data: [
    { region: "North", sales: 42 }, { region: "South", sales: 68 },
    { region: "East", sales: 30 },  { region: "West", sales: 54 },
  ],
  schema: {
    region: { type: "categorical", domain: ["North", "South", "East", "West"] },
    sales:  { type: "quantitative", domain: [0, 80] },
  },
  marks: [
    barX({
      fill: "#0d9488",
      channels: {
        y: { field: "region" },
        x: { field: "sales" },
      },
    }),
  ],
}))

Stacked bars

stack: true stacks the bars that share a band: each segment sits on the cumulative total of the ones before it. The stack's grouping is its band — rows with the same x (or y, for barX) stack together — so there's no grouping option to set. Declare a schema domain covering the stacked total, not the individual values.

Segments are ordered by the mark's series field, so the same category sits at the same height in every band. stack: true says only whether to stack; which rows form a series is the series channel's job, and with none it falls back to fill's field (then stroke's). Span mode wins over stack: give the value axis x1/x2 or y1/y2 and the bars draw as spans instead.

A stacked bar chart

stack: true with fill: { field: "asset" }. The pct domain covers the total, [0, 100].

mount(Elicit({
  width: 380, height: 240,
  margins: { top: 16, right: 16, bottom: 28, left: 40 },
  data: [
    { year: "2023", asset: "stocks", pct: 50 },
    { year: "2023", asset: "bonds",  pct: 30 },
    { year: "2023", asset: "cash",   pct: 20 },
    { year: "2024", asset: "stocks", pct: 65 },
    { year: "2024", asset: "bonds",  pct: 20 },
    { year: "2024", asset: "cash",   pct: 15 },
  ],
  schema: {
    year:  { type: "categorical", domain: ["2023", "2024"] },
    asset: { type: "categorical", domain: ["stocks", "bonds", "cash"] },
    pct:   { type: "quantitative", domain: [0, 100] },
  },
  legends: true,
  marks: [
    bar({
      stack: true,
      channels: {
        x:    { field: "year" },
        y:    { field: "pct" },
        fill: { field: "asset" },
      },
    }),
  ],
}))

Slicing a stack

A stacked bar divides one total among its rows, so three gestures reshape it — the same three that work on a pie or donut, which divide a total the same way:

  • edit.stack.cut() — click inside a segment to divide it in two at that point.
  • edit.stack.edge() — drag a boundary to move value across it. Only the two segments it separates change.
  • edit.stack.merge() — double-click a boundary to fuse those two back into one.

All three preserve the band's total: cutting divides a magnitude, dragging moves value from one row to its neighbour, merging adds two into one. Boundary handles appear once one of these edits is wired, and follow the shared handles / handleSize / handleColor contract.

A cut mints a row, and its category comes from the schema's domain — so building a stack takes no typing. A closed domain (the default) hands out the values that band doesn't yet use, and refuses the cut once they run out. Each band has its own copy of the vocabulary, so using bonds in 2023 doesn't stop 2024 from using it.

Set open: true on the field's schema entry and the domain becomes a starting set instead: a cut appends a new category to it, named from label ("Category" by default) for you to rename later with edit.scale.categories(). An open field also skips the out-of-domain check on seed data.

Cut a stack into parts

Each year starts as one 100% block. The asset domain declares four categories, so each band takes four cuts.

mount(Elicit({
  width: 380, height: 260,
  margins: { top: 16, right: 16, bottom: 28, left: 40 },
  data: [
    { year: "2023", asset: "stocks", pct: 100 },
    { year: "2024", asset: "stocks", pct: 100 },
  ],
  schema: {
    year:  { type: "categorical", domain: ["2023", "2024"] },
    asset: { type: "categorical", domain: ["stocks", "bonds", "cash", "gold"] },
    pct:   { type: "quantitative", domain: [0, 100] },
  },
  legends: true,
  marks: [
    bar({
      stack: true,
      channels: {
        x:    { field: "year" },
        y:    { field: "pct" },
        fill: { field: "asset" },
      },
      edits: [
        edit.stack.cut(),
        edit.stack.edge(),
        edit.stack.merge(),
      ],
    }),
  ],
}))
Try: Click inside a segment to cut it, drag a boundary to shift value, double-click one to merge.

An open domain

holding is declared open, so each cut adds a category rather than running out. label: "Holding" names them.

mount(Elicit({
  width: 380, height: 260,
  margins: { top: 16, right: 16, bottom: 28, left: 40 },
  data: [{ year: "2024", holding: "VTI", pct: 100 }],
  schema: {
    year:    { type: "categorical", domain: ["2024"] },
    holding: { type: "categorical", domain: ["VTI"], open: true },
    pct:     { type: "quantitative", domain: [0, 100] },
  },
  legends: true,
  marks: [
    bar({
      stack: true,
      channels: {
        x:    { field: "year" },
        y:    { field: "pct" },
        fill: { field: "holding" },
      },
      edits: [
        edit.stack.cut({ label: "Holding" }),
        edit.stack.edge(),
        edit.stack.merge(),
      ],
    }),
  ],
}))
Try: Click inside a segment to add a holding.

Explicit spans (x1/x2, y1/y2)

Instead of one value drawn from the baseline, give the value axis two explicit endpoints — x1/x2 for barX, y1/y2 for barY — for a span that doesn't start at zero (a Gantt-style range per category). x1/x2 share the same resolved scale as x (likewise y1/y2 with y), so only one needs an explicit type/domain.

Years active per person

barX with x1/x2 spans; y is the category band.

mount(Elicit({
  width: 380, height: 220,
  margins: { top: 14, right: 16, bottom: 26, left: 60 },
  data: [
    { person: "Ada",   start: 1830, end: 1852 },
    { person: "Grace", start: 1930, end: 1992 },
    { person: "Alan",  start: 1931, end: 1954 },
  ],
  schema: {
    person: { type: "categorical", domain: ["Ada", "Grace", "Alan"] },
    start:  { type: "quantitative", domain: [1820, 2000] },
    end:    { type: "quantitative", domain: [1840, 2000] },
  },
  marks: [
    barX({
      fill: "#7b2d8b",
      channels: {
        y: { field: "person" },
        x1: { field: "start" },
        x2: { field: "end" },
      },
    }),
  ],
}))

Brush: edges + body together

brushSpan() combines both: grab near an edge to resize just that end, grab the body to move the whole span. Drag an edge past the other and release — the fields re-sort (start stays ≤ end) with no visual jump.

mount(Elicit({
  width: 380, height: 220,
  margins: { top: 14, right: 16, bottom: 26, left: 60 },
  data: [
    { person: "Ada",   start: 1830, end: 1852 },
    { person: "Grace", start: 1930, end: 1992 },
    { person: "Alan",  start: 1931, end: 1954 },
  ],
  schema: {
    person: { type: "categorical", domain: ["Ada", "Grace", "Alan"] },
    start:  { type: "quantitative", domain: [1820, 2000] },
    end:    { type: "quantitative", domain: [1840, 2000] },
  },
  marks: [
    barX({
      fill: "#2563eb",
      channels: {
        y: { field: "person" },
        x1: { field: "start" },
        x2: { field: "end" },
      },
      edits: [
        brushSpan({ channels: ["x1", "x2"], threshold: 40,
                    edgeInset: 10, guide: true }),
      ],
    }),
  ],
}))
Try: Drag an edge to resize it, the body to move the whole bar, or drag one edge past the other to see it flip.

Editing bars

Put edit: move() on the value channel and a bar drags to rewrite its value. Thin bars are easier to grab with pick: "nearest" — grab from anywhere in the column. A bar dragged to the baseline collapses to zero length but stays grabbable: it keeps a minimum grab target there, with either pick mode, so you can always drag it back up.

Drag a value

y carries edit: move(). Dragging writes y back through the same scale.

mount(Elicit({
  width: 380, height: 260,
  margins: { top: 14, right: 14, bottom: 26, left: 30 },
  data: [
    { x: "A", y: 20 }, { x: "B", y: 45 },
    { x: "C", y: 30 }, { x: "D", y: 60 },
  ],
  schema: {
    x: { type: "categorical", domain: ["A", "B", "C", "D"] },
    y: { type: "quantitative", domain: [0, 100] },
  },
  marks: [
    bar({
      fill: "#4f46e5",
      channels: {
        x: { field: "x" },
        y: { field: "y", edit: move() },
      },
    }),
  ],
}))
Try: Drag a bar up or down.

Nearest pick + self-drawn guide

pick: "nearest" grabs a bar from anywhere in its column; guide: true draws the snap ring.

mount(Elicit({
  width: 380, height: 260,
  margins: { top: 14, right: 14, bottom: 26, left: 30 },
  data: [
    { x: "A", y: 20 }, { x: "B", y: 45 },
    { x: "C", y: 30 }, { x: "D", y: 60 },
  ],
  schema: {
    x: { type: "categorical", domain: ["A", "B", "C", "D"] },
    y: { type: "quantitative", domain: [0, 100] },
  },
  marks: [
    bar({
      fill: "#2563eb",
      channels: {
        x: { field: "x" },
        y: { field: "y",
             edit: move({ pick: "nearest", threshold: 40, guide: true }) },
      },
    }),
  ],
}))
Try: Drag from anywhere in a column to grab that bar.

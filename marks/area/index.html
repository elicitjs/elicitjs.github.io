Area

A filled path under a series — the distributional sibling of line. Same grouping / ordering knobs; optional handles so sweep and drag reuse the line edit machinery. areaY fills to the y baseline; areaX to the x baseline. Declare an endpoint pair instead (y1 + y2) and it fills between them rather than down to the baseline — an uncertainty band, editable by both edges.

API reference

area(options) · areaY(options) · areaX(options)

Import from elicit.plot. One filled path per series, with an optional draggable handle per datum. areaY fills to the y baseline, areaX to the x baseline; bare area infers the value axis.

area({ channels, orientation, curve, connect, handles, handleSize, handleColor, edits, id }) → Feature
areaY(options) → Feature   // value on y
areaX(options) → Feature   // value on x
Options
OptionTypeDefaultDescription
channelsobject{}Channel map — see Channels.
orientation'vertical' | 'horizontal'autoWhich axis the value runs along ('vertical' = y). Inferred from a band scale, an endpoint pair, or the lone bound channel; areaY / areaX pin it.
channels.serieschannelautoThe column grouping points into separate areas. Defaults to fill’s field, then stroke’s.
channels.orderchannel—The column each series is sorted by, when array order and the domain axis are both wrong.
connect'domain' | 'sequence''domain'How points join when no order channel is given: sorted by the domain axis, or as drawn.
curvestring'linear'Interpolation between handles (e.g. "catmullRom", "step").
handlesboolean | 'hit'truetrue draws a grabbable circle per datum. 'hit' keeps the grab target but draws nothing. false is neither drawn nor grabbable.
handleSizenumber5Pixel radius of each handle.
handleColorstringthemeHandle fill. Defaults to the theme’s handle colour.
edits, id——As on every mark. Area authoring edits live under edit.line.*, which it shares with line.
Channels
ChannelTypeDescription
x / ylinear | point | timeDomain and value axes (same as line).
y1 / y2 · x1 / x2linearAn endpoint pair on the value axis: fill between the two fields instead of down to the baseline (a confidence band, a fan chart). They share the value axis’s scale, so they resolve exactly like y, and declaring a pair picks the value axis on its own. Handles appear on both edges. Same span/baseline split bar and rect make, spelled the same way.
fill / strokeconst | fieldArea fill (default fillOpacity 0.35) and outline. A field here also becomes the default series grouping.
Returns / emits

A feature emitting one filled path per series plus optional handle circles.

Filled series

Drag handles to reshape the belief curve.

Editable area

areaY with drag on y handles.

mount(Elicit({
  width: 400, height: 260,
  margins: { top: 16, right: 16, bottom: 28, left: 34 },
  data: [
    { t: 1, n: 20 }, { t: 2, n: 45 }, { t: 3, n: 35 },
    { t: 4, n: 60 }, { t: 5, n: 50 },
  ],
  schema: {
    t: { type: "quantitative", domain: [1, 5] },
    n: { type: "quantitative", domain: [0, 100] },
  },
  marks: [
    areaY({
      fill: "#2563eb", stroke: "#2563eb",
      channels: {
        x: { field: "t" },
        y: { field: "n", edit: move() },
      },
    }),
  ],
}));
Try: Drag a handle to reshape the area.

Invisible handles

handles: 'hit' keeps the grab targets without drawing the circles — the shared contract with line and arc (false is neither drawn nor grabbable).

handles: 'hit'

Same area as Basics; the grips are invisible but still dragable.

// handles: 'hit' — invisible but grabbable (shared contract with line/arc).
mount(Elicit({
  width: 400, height: 260,
  margins: { top: 16, right: 16, bottom: 28, left: 34 },
  data: [
    { t: 1, n: 20 }, { t: 2, n: 45 }, { t: 3, n: 35 },
    { t: 4, n: 60 }, { t: 5, n: 50 },
  ],
  schema: {
    t: { type: "quantitative", domain: [1, 5] },
    n: { type: "quantitative", domain: [0, 100] },
  },
  marks: [
    areaY({
      handles: 'hit',
      fill: "#2563eb", stroke: "#2563eb",
      channels: {
        x: { field: "t" },
        y: { field: "n", edit: move() },
      },
    }),
  ],
}));
Try: Drag along the upper edge where a handle would sit.

Uncertainty band

Give the value axis an endpoint pair and the area fills between them — the shape of a confidence interval or a fan chart. Both edges get handles, so the interval is elicited by dragging its ends. Pair it with ordering so the band cannot be turned inside-out: drag the low edge above the high one and the high edge is carried along, because the edge you grabbed is the one you meant.

An editable confidence band

areaY with a y1/y2 pair; ordering keeps lo ≤ hi.

mount(Elicit({
  width: 400, height: 260,
  margins: { top: 16, right: 16, bottom: 28, left: 34 },
  data: [
    { year: 2025, lo: 20, hi: 45 }, { year: 2026, lo: 25, hi: 60 },
    { year: 2027, lo: 22, hi: 72 }, { year: 2028, lo: 18, hi: 85 },
  ],
  schema: {
    year: { type: "quantitative", domain: [2025, 2028] },
    lo:   { type: "quantitative", domain: [0, 100] },
    hi:   { type: "quantitative", domain: [0, 100] },
  },
  // A dataset invariant: it holds whichever edge you grab.
  constraints: [ ordering({ field: ["lo", "hi"] }) ],
  marks: [
    areaY({
      fill: "#2563eb", stroke: "#2563eb",
      channels: {
        x:  { field: "year" },
        // An endpoint PAIR instead of a single value: fill BETWEEN the two
        // fields rather than down to the baseline. Declaring the pair is what
        // picks the value axis, and both edges get handles.
        y1: { field: "lo", edit: move({ channels: ["y1"] }) },
        y2: { field: "hi", edit: move({ channels: ["y2"] }) },
      },
    }),
  ],
}))
Try: Drag either edge — push the low edge past the high one and the band moves rather than turning inside-out.
